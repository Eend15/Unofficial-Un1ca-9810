# Dynamic Island 0.1.12-dev7 · Test build: media action icons

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.12-dev6.

## Fix

- Media custom actions such as Favorite use a smaller visual size, matching the previous/next icon slot. Their touch area and callbacks are unchanged.
- Tinted drawable icons are centred with their original aspect ratio instead of being forced into a square. This addresses the oversized, stretched favorite icon reported in #2, in the shade player and island card.

## Validation

- Pixel regression tests cover custom-action size, wide bitmap and tall non-bitmap icons, missing intrinsic dimensions, and the touch target and callback.
- Additional checks cover a framework favorite-star resource, high-density rendering, press animation, and both custom actions through the actual shade player's scaled rendering and touch mapping.
- Checked in headless tests and renders; **not yet confirmed on a real phone**.

## 한국어

0.1.12-dev6 위에 얹은 테스트용 프리릴리스입니다.

### 수정

- 즐겨찾기 같은 미디어 커스텀 버튼의 아이콘을 이전·다음 버튼과 같은 크기 기준으로 줄였습니다. 터치 영역과 버튼 동작은 유지합니다.
- 단색으로 칠하는 아이콘도 원래 가로세로 비율을 유지해 가운데 배치합니다. 알림창 음악 플레이어와 아일랜드 카드에서 즐겨찾기 아이콘이 크고 늘어나 보이던 #2 제보에 대응한 수정입니다.

### 검증

- 픽셀 회귀 테스트로 커스텀 버튼 크기, 가로로 긴 비트맵·세로로 긴 비트맵 외 아이콘, 고유 크기 없는 아이콘, 터치 영역과 동작을 확인합니다.
- 프레임워크 즐겨찾기 별 리소스, 고밀도 화면, 눌림 효과와 실제 알림창 플레이어의 축소 렌더링·터치 좌표 변환을 통한 양쪽 커스텀 버튼도 추가 확인합니다.
- 헤드리스 테스트·렌더 환경에서 검증하며, **실제 기기에서는 아직 확인하지 못했습니다.**
