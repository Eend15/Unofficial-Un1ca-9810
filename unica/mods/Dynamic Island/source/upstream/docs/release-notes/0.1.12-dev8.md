# Dynamic Island 0.1.12-dev8 · Voice recording cards

Based on 0.1.12-dev7. A pre-release fixing the duplicate music player shown during Samsung Voice Recorder recording (#1).

- Samsung Voice Recorder's non-media ongoing activity identifies recording, including paused recordings. The raw activity store is checked even when the app is in the foreground or its activity is only in the Now Bar, and the media session's Android user must match.
- Recording sessions are excluded before music-player selection and from the shade-card lookup. Ended recording sessions cannot come back through the retired-player cache. Fresh playback metadata/state after recording can enable saved-file playback again.
- Only the recording session's media-player row is hidden. The separate recording-controls card stays. Hidden rows are restored on playback/settings/source changes without relying on draw callbacks from a GONE view.
- The shade override switch and touch-exploration fallback retain their stock behaviour.
- All **235 automated tests pass**, covering recording, pause, saved-file playback, other music apps/users, caches, event ordering and shade row restoration. The recording duplication fix was also **confirmed working on a real device** using the locally signed test APK.
- This release uses the project's normal signing key. If you installed the locally signed test APK, uninstall that test APK before installing this release because its signature is different. Restart System UI after installation.

## 한국어

0.1.12-dev7 기반의 프리릴리스로, 삼성 음성 녹음 중 음악 플레이어가 중복 표시되는 #1 문제를 수정합니다.

- 삼성 음성 녹음의 미디어가 아닌 진행 중 활동으로 녹음·녹음 일시정지를 판별합니다. 앱을 사용 중이거나 Now Bar에만 활동이 있어도 원본 상태를 읽으며, 미디어 세션의 Android 사용자도 일치해야 합니다.
- 음악 카드를 선택하기 전에 녹음 세션을 제외하고, 알림창 조회와 종료된 세션 캐시에서도 같은 기준을 적용합니다. 녹음 종료 후 새로운 재생 메타데이터·상태가 오면 저장 파일 재생을 허용합니다.
- 녹음 세션의 미디어 플레이어 행만 숨기고, 별도의 녹음 조작 카드는 유지합니다. 숨겨진 뷰의 그리기에 의존하지 않고 재생·설정·소스 변경 시 행을 복원합니다.
- 알림창 플레이어 변경을 끄거나 터치 탐색을 사용할 때는 기본 동작을 유지합니다.
- 녹음·일시정지·저장 파일 재생·다른 음악 앱과 사용자·캐시·이벤트 도착 순서·알림창 행 복원을 포함한 **자동 테스트 235개가 통과**했습니다. 녹음 중복 표시 수정은 로컬 테스트 APK로 **실제 기기에서도 정상 동작을 확인**했습니다.
- 이 릴리스는 프로젝트의 기존 배포 키로 서명합니다. 별도 테스트 키로 서명한 로컬 APK를 설치했다면, 서명이 다르므로 해당 테스트 APK를 삭제한 뒤 이 릴리스를 설치하세요. 설치 후 시스템 UI를 재시작하세요.
