# Dynamic Island 0.1.12-dev14 · Local test: remove the grey backdrop during folding

Based on local dev13, retaining all six languages and the reviewed notification/appearance options. No push or release is included.

- Separates each card's native Samsung blur backdrop from its painted surface. The backdrop fades independently while the card keeps painting its opaque return to the black pill; changing opacity no longer requires rebuilding native blur every frame.
- Finishes the backdrop fade early in the fold, before the compact-pill handoff. The native layer is cleared when its contribution reaches zero, on an unplaced frame and immediately on release. The existing brief painted-surface linger does not retain native blur.
- Clips the backdrop to the current rounded shape so an approximate native corner radius cannot leave a rectangular patch around a shrinking card.
- Regression: 60Hz/120Hz late-fold backdrop tests and the legacy closing path failed before the change and pass afterwards. Additional lifecycle checks cover independent opacity, the painted foreground after blur removal, current clipping, missed placement and immediate release cleanup.
- Headless tests model the native backdrop through an injected backend; Samsung's actual compositor behaviour still needs confirmation on the device that showed the grey patch.

## 한국어

로컬 dev13 기반이며 6개 언어와 기존 알림·모양 옵션을 유지합니다. 이번 작업에는 푸시·릴리스가 포함되지 않습니다.

- 카드의 삼성 네이티브 블러 배경과 카드 그림을 분리합니다. 블러만 먼저 줄이고, 카드는 검은 알약으로 돌아가는 불투명한 표면을 계속 그립니다. 투명도를 바꿀 때 매 프레임 네이티브 블러를 다시 만들지 않습니다.
- 알약으로 합쳐지기 전에 블러의 페이드를 끝냅니다. 기여도가 0이 되거나 배치가 빠진 프레임, 카드 제거 시에는 네이티브 블러를 정리합니다. 카드 그림의 짧은 유지 시간에는 블러가 남지 않습니다.
- 현재 둥근 모양에 맞춰 블러를 잘라, 접히는 카드 밖으로 사각형 조각이 남는 경로도 줄입니다.
- 수정 전 실패했던 60Hz·120Hz 및 기존 애니메이션 접힘 후반 검사가 통과합니다. 별도 투명도, 블러 제거 후 카드 그리기, 현재 모양의 클리핑, 누락 프레임과 즉시 제거 정리를 함께 검사합니다.
- 헤드리스 검사는 주입한 블러 백엔드로 생명주기를 모델링합니다. 실제 삼성 합성 화면에서 회색 조각이 없어졌는지는 증상이 보였던 기기로 확인해야 합니다.
