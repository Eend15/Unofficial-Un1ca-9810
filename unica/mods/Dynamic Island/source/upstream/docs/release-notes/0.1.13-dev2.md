# Dynamic Island 0.1.13-dev2 · Music-reactive shared glow

**Development pre-release** · Changes since **0.1.13-dev1** · **English** / [한국어](#한국어)

This build brings the glow changes from local test v4 to an officially signed development release, together with the notification compatibility update already on main.

## Shared, music-reactive glow

- **All compact pills follow the same music session.** The main pill and additional bubble share album colours, movement and sound response, even when the music pill is hidden by the foreground app or its paused-card timeout has elapsed. Album matching uses the same vivid palette as the music waveform.
- **Enabled by default, for music sessions only.** Previously saved on/off choices are preserved. Select **When to show glow → For all activities** to keep the glow outside music sessions as well. Theme colours, separate presets and HSV/HEX colours remain available; album matching can be disabled independently.
- **Separate brightness and dynamic strength.** Brightness defaults to **45%**. The new **0–100% dynamic effect** slider defaults to **50%**, ranging from static or barely moving to a strong colour flow and sound response. The settings preview demonstrates the effect while adjusting it.
- **Pause and session transitions.** Pausing makes every pill's glow very faint and gradually settles the motion. When the music session ends, its last colours fade out together over **1.2 seconds**, rather than disappearing abruptly or flashing the default colour. A new session can smoothly interrupt that fade.
- The effect reuses the audio-output analyser and cached halo mask. Audio capture stops when no visible effect needs it; low-performance mode disables the glow while preserving its settings. Voice-recording sessions remain excluded from music selection.

## Notification compatibility

The existing **Advanced & troubleshooting → Experimental notification recovery** option now selects the alternate One UI 8 notification handling from the supplied build. When enabled, ordinary banner/list scans allow notifications from the open app and group summaries, and use its stock-banner removal behaviour. Now Bar activity recovery remains tied to the same option. The option is **off by default**; ordinary behaviour remains unchanged while it is off. Notification display modes, app exclusions and verification-code settings still apply.

## Validation and installation

- **88 default Android tests passed**, including shared glow colours, pause/end transitions, hidden and expired music cards, recording exclusion, settings persistence and compatibility handling. Native render captures cover paired pills and session fading.
- **506/506 translated strings** in English, Korean, Japanese, Simplified Chinese, Russian and Turkish; translation-tool tests also passed. All six READMEs describe the new defaults and controls.
- This release uses the normal official APK signing key and updates previous official builds. **If a separately signed local test APK is installed, save any settings you need and uninstall it before installing the official release.** Restart SystemUI or reboot after installation.

## 한국어

로컬 테스트 **v4의 글로우 변경사항**과 main에 반영했던 알림 호환성 수정을 공식 서명한 개발 프리릴리즈입니다. **0.1.13-dev1 이후 변경사항**을 담았습니다.

### 음악에 반응하는 공통 글로우

- **모든 작은 알약이 같은 음악 세션을 따릅니다.** 메인 알약과 추가 버블이 앨범 색·움직임·소리 반응을 공유합니다. 음악 앱을 보고 있어 음악 알약이 숨겨졌거나 일시정지 카드 표시 시간이 지나도 실제 세션이 남아 있으면 적용됩니다. 앨범 연동은 음악 파형과 같은 선명한 색상을 사용합니다.
- **기본 켜짐·음악 세션 전용**입니다. 기존에 저장한 켜짐·꺼짐 선택은 보존합니다. **글로우 표시 조건 → 모든 활동에 표시**를 선택하면 음악 세션이 없을 때도 표시할 수 있습니다. 테마색·개별 프리셋·HSV·HEX 색상과 별도 앨범 연동 설정을 유지합니다.
- **밝기와 다이내믹 효과 강도를 따로 조절합니다.** 밝기는 기본 **45%**, 새 다이내믹 효과는 **0–100%·기본 50%**입니다. 정적이거나 거의 느껴지지 않는 수준부터 강한 색 흐름·소리 반응까지 조절하며 설정 미리보기에서 확인할 수 있습니다.
- **일시정지·세션 종료도 부드럽게 전환합니다.** 일시정지하면 모든 알약의 빛이 매우 희미해지고 움직임도 서서히 잦아듭니다. 세션이 끝나면 기본 색으로 튀거나 갑자기 사라지지 않고 마지막 앨범 색을 유지한 채 **1.2초 동안 함께 사라집니다.** 도중에 새 세션이 생겨도 부드럽게 이어집니다.
- 기존 오디오 출력 분석과 캐시된 글로우 마스크를 재사용합니다. 보이는 효과에 필요하지 않으면 오디오 수집을 멈추고, 저사양 모드에서는 설정을 보존한 채 글로우를 끕니다. 녹음 세션은 음악 선택에서 계속 제외합니다.

### 알림 호환성

기존 **고급 설정 및 문제 해결 → 실험적 알림 복구** 옵션을 켜면 제공받은 One UI 8 빌드의 대체 알림 처리 방식을 사용합니다. 일반 배너·알림 목록 검사에서 사용 중인 앱과 묶음 요약 알림을 허용하고, 해당 빌드의 기본 배너 제거 방식을 사용합니다. Now Bar 활동 복구도 같은 옵션에 연결됩니다. **기본 꺼짐**이며 끄면 기존 동작을 유지합니다. 알림 표시 모드·앱 제외·인증번호 설정은 계속 적용됩니다.

### 검증과 설치

- **기본 안드로이드 테스트 88개 통과**: 알약 간 색상 공유, 일시정지·종료 전환, 숨겨지거나 표시 시간이 지난 음악 카드, 녹음 제외, 설정 저장과 호환성 처리를 포함합니다. 실제 렌더러로 알약 두 개와 세션 페이드를 검토했습니다.
