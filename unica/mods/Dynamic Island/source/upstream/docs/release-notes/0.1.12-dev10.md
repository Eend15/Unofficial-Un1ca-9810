# Dynamic Island 0.1.12-dev10 · Album-coloured waveform

**English** · [한국어](#한국어)

A pre-release based on 0.1.12-dev9, implementing the gradient waveform requested in #5.

## Changes

- The compact music waveform now uses one horizontal, three-stop gradient across all four bars, instead of one flat colour. Its palette follows the album artwork rather than a fixed rainbow.
- Meaningful colours near the dominant artwork hue are selected and adjusted for visible hue, saturation and lightness variation on the black island. Narrow/single-colour artwork uses a bounded analogous expansion; true grayscale stays neutral. A substantial muted colour family can be recovered without allowing tiny coloured logos to recolour a grayscale cover.
- Colours crossfade together over 500 ms when artwork changes, including secondary-only changes with the same primary colour. Interrupted fades continue from the currently displayed colours. Paused players keep receiving frames until their palette transition finishes.
- Palette extraction is cached with the cover; it is not repeated per animation frame. Hardware/recycled/missing artwork has safe fallbacks, and temporary bitmap cleanup does not recycle the original cover.
- Live-audio following, paused bar geometry and non-media waveform colours are unchanged. The expanded card keeps its existing scalar-accent glow rendering.

## Validation and installation

- Local release build, compilation of all test sources, and 20 pure-JVM palette/transition tests passed. Regression tests also cover bitmap/cache handling, rendered gradients, opacity, shader reuse and paused frame scheduling; the release workflow runs the complete suite on Linux x86_64 before signing and publishing.
- Five supplied album screenshots were cropped to artwork only for colour comparisons. Those comparisons are illustrations using the production Java extractor, not device captures; bitmap downsampling in previews approximates Android filtering.
- **Not yet confirmed in a real System UI session on a device.** Feedback on album colours and small-screen appearance is welcome.
- This APK uses the project's normal release signing key. Update and restart System UI after installation.

## 한국어

0.1.12-dev9 기반의 프리릴리스로, #5에서 요청한 음악 파형 그라데이션을 구현합니다.

### 변경

- 작은 음악 아일랜드의 파형을 단색 대신 막대 4개 전체에 이어지는 가로 3색 그라데이션으로 표시합니다. 고정 무지개색이 아니라 앨범 아트에 맞춰 색이 바뀝니다.
- 앨범의 지배적인 색과 가까운 실제 색들을 고르고, 검은 아일랜드에서도 변화가 보이도록 색조·채도·명도를 보정합니다. 단색이나 색 범위가 좁은 앨범은 제한된 유사색으로 확장하고, 흑백은 중립색을 유지합니다. 작은 컬러 로고가 흑백 앨범 전체를 물들이지 않도록 하면서 충분한 면적의 저채도 색은 복구합니다.
- 앨범 변경 시 팔레트 전체가 500ms 동안 부드럽게 바뀝니다. 대표색이 같고 보조색만 달라져도 전환하며, 도중에 새 앨범이 와도 현재 표시색에서 이어집니다. 일시정지 상태에서도 색 전환이 끝날 때까지 프레임을 갱신합니다.
- 팔레트는 앨범 이미지와 함께 캐시해 매 프레임 추출하지 않습니다. 하드웨어·해제·누락 비트맵은 안전하게 처리하고 임시 이미지를 정리할 때 원본을 해제하지 않습니다.
- 실시간 오디오 반응, 일시정지 시 막대 모양과 음악 외 파형 색은 유지합니다. 펼친 카드의 기존 대표색 글로우 렌더링은 그대로 사용합니다.

### 검증과 설치

- 로컬 릴리스 빌드, 전체 테스트 소스 컴파일과 순수 JVM 팔레트·전환 테스트 20개가 통과했습니다. 비트맵·캐시, 그라데이션 픽셀, 투명도, 셰이더 재사용과 일시정지 프레임 예약 회귀 테스트도 추가했으며, 릴리스 워크플로가 Linux x86_64에서 전체 테스트를 수행한 뒤 서명·배포합니다.
- 제공받은 앨범 화면 5개에서 앨범 부분만 잘라 색을 비교했습니다. 비교 이미지는 실제 Java 추출기를 사용하는 시안이며 기기 캡처가 아닙니다. 미리보기의 이미지 축소는 Android 필터링을 근사합니다.
- **실제 기기의 System UI 세션에서는 아직 확인하지 못했습니다.** 앨범 색과 작은 화면에서의 표현에 대한 피드백을 부탁드립니다.
- APK는 프로젝트의 기존 배포 키로 서명합니다. 업데이트 후 시스템 UI를 재시작하세요.
