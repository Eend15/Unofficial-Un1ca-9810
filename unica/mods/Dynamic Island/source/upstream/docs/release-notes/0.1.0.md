# Dynamic Island 0.1.0 · 첫 릴리스

**English** · [한국어](#한국어)

A Dynamic Island for Samsung One UI. It replaces the Now Bar capsule in the status bar with a pill and cards, and turns ordinary notifications into live cards. An LSPosed module for System UI, inspired by @cryyear's DynamicIsland ([github.com/Spottq](https://github.com/Spottq)) and implemented anew.

## Highlights

- **Live notifications as cards:** every System UI ongoing activity gets a compact pill and an expanded card (header, chronometer, description, plain / segmented / indeterminate progress, buttons, work profile badge). Calls, cast, screen recording, timers and a music player (seek bar, art-tinted glow, waveform, output route) are included.
- **Ordinary notifications as cards:** messages and banners open as island cards instead of the heads-up banner; verification codes get a card with a Copy button; downloads, copies and updates become progress cards (even when progress is written only as text); voice-chat calls get a call card.
- **Rules as data:** delivery, pickup, parcel, ride, route, wearable and battery cards come from a rule file in LiveBridge's dictionary format. A Korean rule file is built in, nothing is downloaded and the app has no network permission.
- **Rule manager:** a switch per rule, stages, apps and wording of each rule (add your own, or create a new rule), a tester that shows what a notification text would become, import / export through the clipboard.
- **System events:** charging, low battery, sound mode, Bluetooth audio with battery level, camera / microphone / location in use, quick-setting feedback.
- **App control:** a blacklist or whitelist of apps for the ordinary-notification features.
- **Motion:** spring animations with squash and stretch and a liquid bridge between pill and card.
- **One UI style settings app** in Korean and English, with a diagnostics page.
- **Safety:** hook groups are isolated, a crash guard switches the module off after repeated System UI crashes, and the diagnostics report shows what the module did inside System UI.

## Requirements and install

- Samsung device on One UI 8 / 9 (Android 16 / 17), LSPosed. Root is only needed for the optional "Restart System UI" button.
- Install the APK, enable **Dynamic Island** in LSPosed with the scope **System UI** (`com.android.systemui`), then restart System UI or reboot.
- The app id is `dev.android.dynamicisland`. If you installed an earlier test build, uninstall it first.
- Every release is signed with the same key, so later versions install as updates over this one.

## Please note

- This version has been verified in a headless test and render environment (143 unit and render tests), **not on a real device**. System UI internals differ between builds, so something may not work on your phone. Open **Tools → Diagnostics**, copy the report and send it with an issue.
- Known limitations: tapping a card in the notification shade does not dismiss the notification; after dragging the card stack sideways a button tap can land slightly off; verification codes made only of lowercase letters and digits are not detected.
- Independent, unofficial project; not affiliated with or endorsed by Samsung. Use it at your own risk.

## 한국어

삼성 One UI용 다이나믹 아일랜드입니다. 상태바의 Now Bar 캡슐을 알약과 카드로 바꾸고, 일반 알림도 라이브 카드로 보여 줍니다. 시스템 UI에서 동작하는 LSPosed 모듈이며, @cryyear의 DynamicIsland([github.com/Spottq](https://github.com/Spottq))에서 영감을 받아 새로 구현했습니다.

### 주요 기능

- **라이브 알림 카드:** 시스템 UI의 모든 진행 중 활동에 작은 알약과 펼친 카드를 제공합니다(헤더, 스톱워치, 설명, 일반·구간·불확정 진행바, 버튼, 업무 프로필 배지). 통화, 캐스트, 화면 녹화, 타이머, 음악 플레이어(시크바, 앨범 색 글로우, 파형, 출력 위치)도 포함합니다.
- **일반 알림 카드:** 메시지와 배너를 헤드업 배너 대신 아일랜드 카드로 보여 줍니다. 인증번호에는 복사 버튼이 있는 카드, 다운로드·복사·업데이트에는 진행 카드(진행률이 글자로만 적혀 있어도), 음성 채팅 통화에는 통화 카드를 보여 줍니다.
- **데이터로 된 규칙:** 배달, 픽업, 택배, 택시, 길안내, 웨어러블, 배터리 카드는 LiveBridge 사전 형식의 규칙 파일에서 옵니다. 한국어 규칙이 내장되어 있고, 다운로드가 없으며 앱에 네트워크 권한도 없습니다.
- **규칙 관리:** 규칙별 스위치, 규칙마다 단계·앱·문구(직접 추가하거나 새 규칙 만들기), 알림 글이 어떤 카드가 되는지 확인하는 시험, 클립보드로 가져오기·내보내기를 지원합니다.
- **시스템 이벤트:** 충전, 배터리 부족, 소리 모드, 배터리가 보이는 블루투스 오디오, 카메라·마이크·위치 사용, 빠른 설정 피드백을 보여 줍니다.
- **앱 관리:** 일반 알림 기능에 대해 앱 블랙리스트 또는 화이트리스트를 지정합니다.
- **모션:** 스프링 애니메이션, 찌그러짐·늘어남 효과, 알약과 카드 사이의 액체 연결.
- **One UI 스타일 설정 앱**(한국어·영어)과 진단 페이지.
- **안전장치:** 후크는 그룹별로 격리되고, 시스템 UI가 반복해서 죽으면 크래시 가드가 모듈을 끄며, 진단 리포트로 모듈이 시스템 UI 안에서 한 일을 볼 수 있습니다.

### 요구 사항과 설치

- One UI 8 / 9(Android 16 / 17)의 삼성 기기와 LSPosed. 루트는 선택 기능인 "시스템 UI 재시작" 버튼에만 필요합니다.
- APK를 설치하고, LSPosed에서 **Dynamic Island**를 활성화한 뒤 범위를 **시스템 UI**(`com.android.systemui`)로 지정하고, 시스템 UI를 재시작하거나 재부팅합니다.
- 앱 ID는 `dev.android.dynamicisland`입니다. 이전 테스트 빌드를 설치했다면 먼저 삭제하세요.
- 모든 릴리스는 같은 키로 서명되므로 이후 버전은 이 버전 위에 업데이트로 설치됩니다.

### 알아 두세요

- 이 버전은 헤드리스 테스트·렌더 환경(단위·렌더 테스트 143개)에서만 검증했고 **실제 기기에서는 검증하지 못했습니다.** 시스템 UI 내부는 빌드마다 달라서 폰에 따라 동작하지 않는 부분이 있을 수 있습니다. **도구 → 진단**에서 리포트를 복사해 이슈와 함께 보내 주세요.
- 알려진 한계: 알림창의 카드를 눌러도 알림이 지워지지 않습니다. 카드 묶음을 옆으로 끈 뒤에는 버튼 터치 위치가 조금 어긋날 수 있습니다. 소문자와 숫자로만 된 인증번호는 감지하지 못합니다.
- 삼성과 무관한 독립 비공식 프로젝트입니다. 사용에 따른 책임은 사용자에게 있습니다.
