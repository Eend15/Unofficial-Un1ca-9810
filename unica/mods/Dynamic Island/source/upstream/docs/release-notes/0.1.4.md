# Dynamic Island 0.1.4 · Smoother animations

**English** · [한국어](#한국어)

This release is about how the island moves. Every part of it that opens, closes, swaps or appears was watched frame by frame and smoothed out. Nothing was added or removed; it just feels better.

## What you will notice

- **Opening the cards on a dark screen.** The shape used to be hard to follow on a black wallpaper because the island has no outline while it changes shape. Now a light outline is there from the very first moment, so you can see the pill grow into cards. When the cards have settled, the outline becomes the usual soft rim.
- **Two or more cards.** The cards used to unfold the wrong way round: the lower card came out on top of the upper one, as if the stack opened upside down. Now the top card, the one closest to the pill, comes out first and stays in front, and the others slide out from behind it. Closing works the other way round: the lower cards slide back behind the top card and fold into the pill.
- **Closing the cards.** Before, the pill shrank to a tiny dot when the cards folded in and only then grew back, and the end of the animation had a small jump. Now the pill is already growing back while the cards fold into it, the cards end up exactly the shape of the pill, and the last little bounce is gone. The outline also stays the same all the way to the end, so nothing flickers at the last moment.
- **Changing what the pill shows.** When the pill switches from one item to another, the old content used to disappear completely for a split second before the new one appeared, which looked like a flicker on a black screen. Now the new content starts to fade in while the old one is still fading out.
- **The small circle next to the pill.** When you set an item aside, a small circle splits off from the pill like a drop of liquid. A thin grey stub used to stay behind for a single frame at the moment it let go; it is gone.
- **When the pill first appears.** It used to appear as an empty black bar for a moment and the small circle jumped out while the pill was still landing. Now the icon shows up earlier while the pill is still growing, and the small circle only splits off after the pill has landed and bounced.

## Prefer the old motion?

The smoother animations are on by default. If you liked the old ones better, open **Animation** in the settings, pick **Legacy animation** and tap **Apply**. The change reaches the island within a few seconds, and you can switch back at any time.

## Install and notes

- Install the APK over 0.1.3; it is signed with the same key. Restart System UI afterwards.
- The changes were checked frame by frame in a test environment, **not on a real device**. If an animation looks odd, tell us which one (opening, closing, swapping, the small circle or appearing) and whether the phone has a black wallpaper; that helps a lot. If something does not work at all, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

이번 버전은 아일랜드가 움직이는 방식을 다듬었습니다. 펼쳐지고, 접히고, 바뀌고, 나타나는 모든 동작을 프레임 하나하나 확인하면서 어색한 부분을 고쳤습니다. 기능이 늘거나 줄지는 않았고, 쓸 때의 느낌만 좋아졌습니다.

### 이렇게 달라집니다

- **어두운 화면에서 카드가 펼쳐질 때.** 검은 배경화면에서는 모양이 바뀌는 동안 윤곽이 없어서 움직임이 순간이동처럼 보였습니다. 이제 처음부터 밝은 윤곽이 보여서 알약이 카드로 자라나는 모습을 따라갈 수 있습니다. 카드가 자리를 잡으면 윤곽은 원래의 은은한 테두리로 바뀝니다.
- **카드가 두 개 이상일 때.** 카드가 거꾸로 펼쳐지는 것처럼 보였습니다. 아래 카드가 위 카드 앞으로 튀어나와서 위아래가 뒤집힌 느낌이었습니다. 이제 알약에 가장 가까운 첫 카드가 먼저 나와서 맨 앞에 있고, 나머지 카드는 그 뒤에서 미끄러져 나옵니다. 닫을 때는 반대로 아래 카드가 첫 카드 뒤로 접혀 들어간 다음, 알약으로 모입니다.
- **카드를 닫을 때.** 예전에는 카드가 접혀 들어가면 알약이 점처럼 작아졌다가 다시 커졌고, 끝에서 한 번 툭 끊기는 느낌이 있었습니다. 이제 카드가 접히는 동안 알약이 이미 원래 크기로 자라나고 있어서, 카드가 알약과 똑같은 모양으로 들어갑니다. 마지막에 한 번 더 튀던 출렁임도 없앴고, 윤곽도 끝까지 똑같이 이어져서 마지막 순간에 깜빡이지 않습니다.
- **알약의 내용이 바뀔 때.** 알약이 한 항목에서 다른 항목으로 바뀔 때 예전 내용이 완전히 사라진 뒤에 새 내용이 나와서, 아주 짧은 순간 알약이 텅 비었습니다. 검은 화면에서는 깜빡임처럼 보였습니다. 이제 예전 내용이 사라지는 중에 새 내용이 겹쳐서 나타납니다.
- **알약 옆의 작은 원.** 항목을 옆으로 치우면 알약에서 작은 원이 물방울처럼 떨어져 나옵니다. 떨어지는 순간 알약과 원 사이에 회색 막대 조각이 한 프레임 남던 것을 없앴습니다.
- **알약이 처음 나타날 때.** 알약이 나타나자마자 한동안 빈 검은 막대로 보였고, 알약이 아직 내려앉는 중에 작은 원이 튀어나와 두 동작이 겹쳤습니다. 이제 알약이 커지는 동안 아이콘이 더 일찍 나타나고, 작은 원은 알약이 내려앉아 한 번 튄 다음에 떨어져 나옵니다.

### 예전 움직임이 더 좋다면

부드러운 애니메이션이 기본으로 켜져 있습니다. 예전 움직임이 더 마음에 들면 설정의 **애니메이션**에서 **기존 애니메이션**을 고르고 **적용**을 누르세요. 몇 초 안에 아일랜드에 반영되고, 언제든 다시 바꿀 수 있습니다.

### 설치와 참고

- 0.1.3 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 변경 사항은 테스트 환경에서 프레임 단위로 확인했고 **실제 기기에서는 검증하지 못했습니다.** 움직임이 어색하면 어느 동작인지(펼침, 접힘, 교체, 작은 원, 나타남)와 배경화면이 검은색인지 알려 주시면 큰 도움이 됩니다. 아예 동작하지 않으면 **도구 → 진단**의 리포트를 복사해 이슈와 함께 보내 주세요.
