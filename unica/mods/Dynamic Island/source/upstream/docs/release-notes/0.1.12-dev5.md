# Dynamic Island 0.1.12-dev5 · Test build: animated icons

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.12-dev3.

## What's new

- **The island's pictograms are animated, in a cleaner style.** Battery, charging, power saving, ringer (bell, silent bell, vibrate), headphones, speaker, Do Not Disturb, camera, microphone, location, airplane mode, flashlight, hotspot, rotation lock and download now play short animations when they appear, and they follow the island's colour like before. The bell, silent bell, vibrate, headphones, speaker and moon use the ColorOS icon pack's Lottie animations; the rest are drawn to match.
- The battery, charging and power-saving icons fill to the real charge; the bolt and the plus are cut out of the fill.

## Install and notes

- Install over 0.1.12-dev3; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment, **not on a real device**.

## 한국어

0.1.12-dev3 위에 얹은 테스트용 프리릴리스입니다.

### 새로운 점

- **아일랜드의 아이콘이 더 깔끔한 모양으로 움직입니다.** 배터리, 충전, 절전, 벨(벨, 무음 벨, 진동), 헤드폰, 스피커, 방해 금지, 카메라, 마이크, 위치, 비행기 모드, 손전등, 핫스팟, 화면 회전 잠금, 다운로드가 나타날 때 짧은 애니메이션으로 재생되고, 색은 전과 같이 아일랜드를 따라갑니다. 벨, 무음 벨, 진동, 헤드폰, 스피커, 달은 ColorOS 아이콘 팩의 Lottie 애니메이션을 쓰고, 나머지는 같은 스타일로 그렸습니다.
- 배터리, 충전, 절전 아이콘이 실제 충전량만큼 채워지고, 번개와 플러스는 채움 위에 파내어 보입니다.
