# Dynamic Island 0.1.13-dev1 · Settings, device cards and appearance controls

**Development pre-release** · Changes since stable **0.1.12** · **English** / [한국어](#한국어)

This build collects the changes developed since 0.1.12, including the new optional charging and wired-headset cards. New device cards, statistics, portrait full-screen visibility, ambient glow and low-performance mode are off by default.

## Charging and wired headphones

- **Live charging card:** Under **Notifications → System events**, optionally keep battery current, estimated power, temperature and charge level visible while plugged in. The compact island shows whole watts when available. It keeps the normal event priority and replaces the module's brief charging popup while active.
- **Separate charging statistics:** Off by default and available when the charging card is enabled. Show measured screen-on/off time and estimated net changes in battery percentage and mAh. Elapsed time includes deep sleep; negative charge changes are preserved instead of counted as incoming charge. Coarse fuel-gauge changes are divided over the observed screen-state reporting window.
- **Collection follows the switches:** No additional charging listener or polling is started while the card is disabled, and charge-counter reads stop when statistics are disabled. Live polling pauses with the screen off and uses a slower interval in low-performance mode. Short restart checkpoints are validated; unobserved gaps are excluded.
- **Wired/USB headset alerts:** A separate opt-in switch briefly announces real connection and disconnection changes. Enabling it does not announce devices that were already connected, and duplicate callbacks do not restart the announcement. These alerts do not add a new automatic expansion behavior.
- **Camera text clearance:** **Advanced & troubleshooting → Camera calibration** offers 0–16dp additional space beside the camera cutout, with live preview, numeric input and reset. The default 0dp retains the original spacing; extra clearance is limited to the available island width.

Power is an estimate at the battery, not the charger's rated output. Screen-state charge splits are estimates, and statistics cover observed measurement periods rather than a complete charging-history log. Unavailable readings stay unknown; mAh is hidden when charge-counter data is unavailable. Reporting quality depends on the phone.

## Settings and appearance

- **Simpler settings:** Grouped navigation, clearer titles, three notification modes, searchable app selection with Save/Cancel, simpler rule controls and separate advanced tools. Position, size and camera calibration reset independently; settings refresh/back navigation preserves scroll position.
- **Galaxy-style switches** throughout settings, with native touch behavior and consistent disabled states. The animation page previews the actual island renderer and saves the chosen style immediately.
- **Low-performance mode:** Optionally reduce blur and continuous effects, use static music tint/waveforms/icons, stop audio analysis, and cap ambient rendering at 30fps and interactive motion at 60fps. Individual preferences are retained for when the mode is turned off.
- **Pill outline modes:** Automatic, Always and None. Automatic uses contrast against the sampled background, keeps a conservative fallback when unknown, and rejects stale samples. Sampling stops when the window is hidden.
- **Ambient glow** ([#10](https://github.com/sampple-korea/dynamicisland/issues/10)): A soft outer halo with strength control, theme-following or separate preset/HSV/HEX colours, and optional album-colour matching. Low-performance mode disables the glow while retaining its preferences.
- **Portrait full-screen visibility** ([#14](https://github.com/sampple-korea/dynamicisland/issues/14)): An opt-in Behavior setting keeps active content visible when apps such as Camera hide the status bar. Lock-screen/AOD hiding and the phone's landscape rules remain in effect; an empty island is not forced onto the screen.

## Recording and media fixes

- Preserve screen-recording elapsed time through notification refreshes, key changes and rolling system timestamps; improve compatibility and session-boundary handling ([#17](https://github.com/sampple-korea/dynamicisland/issues/17), contribution [#19](https://github.com/sampple-korea/dynamicisland/pull/19)).
- Harden recorder ownership and lifecycle checks so unrelated sessions and profiles are not incorrectly treated as an active recording.
- Improve media foreground detection to avoid a brief startup island over the player app. Fresh task state takes precedence over stale vendor state; uncertain new sessions receive a short bounded recheck ([#18](https://github.com/sampple-korea/dynamicisland/issues/18)).

## Languages and validation

- New controls and module-owned card text support **English, Korean, Japanese, Simplified Chinese, Russian and Turkish**. English remains the translation source; all six catalogs contain **500/500** translatable strings. The six READMEs and project credits have been refreshed.
- The regular test suite has been reduced to **82 focused checks**. Repetitive cases were removed, and review-image generation is optional with `-Prender`. Local Android checks, APK build, translation checks and two translation-tool tests pass; native card previews were reviewed in all six languages. The release workflow repeats the Android tests before signing.
- This is a pre-release. Headless validation does not replace testing sensor readings, USB headset handling, full-screen overlays or GPU effects on the target phone.

## Install

The release APK uses the project's normal release signing key and can update previous official releases. **A separately signed local test APK must be uninstalled before installing this official build; preserve any settings you need first.** Restart SystemUI or reboot after installation. Use **Advanced & troubleshooting → Diagnostics** when reporting a problem.

## 한국어

정식 **0.1.12 이후 변경사항을 모은 개발 프리릴리즈**입니다. 새 충전 카드·충전 통계·이어폰 알림, 세로 전체 화면 표시, 외곽 글로우와 저사양 모드는 기본 꺼짐입니다.

### 충전과 유선 이어폰

- **충전 상세 카드:** **알림 → 시스템 이벤트**에서 켜면 연결 중 배터리 전류·추정 전력·온도·잔량을 계속 표시합니다. 작은 아일랜드에는 가능한 경우 정수 와트를 표시합니다. 기존 이벤트 우선순위를 유지하며, 활성화된 동안 모듈의 짧은 충전 팝업을 대신합니다.
- **별도 충전 통계:** 기본 꺼짐이며 충전 상세 카드가 켜져 있어야 합니다. 화면 켜짐·꺼짐 시간과 배터리 %·mAh의 추정 순변화를 표시합니다. 깊은 절전 시간도 경과 시간에 포함하고, 충전량 감소를 충전된 양으로 더하지 않습니다. 기기가 충전량을 띄엄띄엄 보고하면 해당 관측 구간의 화면 상태별 시간에 나눠 반영합니다.
- **옵션에 맞춰 수집:** 카드가 꺼져 있으면 추가 충전 수집과 폴링을 시작하지 않고, 통계를 끄면 충전량 카운터 읽기도 멈춥니다. 화면이 꺼지면 주기적 폴링을 멈추며 저사양 모드에서는 갱신 간격을 늘립니다. 짧은 재시작의 저장 기록은 조건을 확인해 복원하고, 관측하지 못한 구간은 제외합니다.
- **유선·USB 이어폰 알림:** 별도 기본 꺼짐 옵션으로 실제 연결·분리를 잠시 표시합니다. 옵션을 켜기 전부터 연결된 기기는 알리지 않고, 중복 콜백으로 알림 시간이 다시 시작되지 않습니다. 새로운 자동 펼침 동작은 켜지지 않습니다.
- **카메라 옆 글자 여백:** **고급 설정 및 문제 해결 → 카메라 구멍 보정**에서 추가 여백을 0–16dp로 조절할 수 있습니다. 실시간 미리보기·숫자 입력·초기화를 지원합니다. 기본 0dp는 기존 간격을 유지하며, 설정한 아일랜드 너비에 들어가는 만큼만 추가합니다.

전력은 충전기 정격이 아닌 배터리 측 추정값입니다. 화면 상태별 충전량 분배도 추정치이며, 통계는 전체 충전 이력이 아닌 관측한 측정 구간을 대상으로 합니다. 제공되지 않는 값은 알 수 없음으로 두고, 충전량 카운터가 지원되지 않으면 mAh를 숨깁니다. 측정 품질은 기기에 따라 달라집니다.

### 설정과 모양

- **설정 구성 정리:** 항목을 그룹으로 묶고 제목을 명확히 했습니다. 알림 표시 방식 3가지, 검색과 저장·취소를 지원하는 앱 선택, 간단한 규칙 설정과 별도 고급 도구를 제공합니다. 위치·크기·카메라 보정을 따로 초기화하며, 새로고침·뒤로 가기에서도 스크롤 위치를 유지합니다.
- **설정 전체에 갤럭시 스타일 스위치**를 적용했습니다. 기본 터치 동작과 일관된 비활성 표시를 유지합니다. 애니메이션 화면은 실제 아일랜드 렌더러로 미리 보고 선택 즉시 저장합니다.
- **저사양 모드:** 블러와 지속 효과를 줄이고 음악 색상·파형·아이콘을 정적으로 표시하며 오디오 분석을 멈춥니다. 지속 움직임은 최대 30fps, 터치·확장·축소는 최대 60fps로 제한합니다. 모드를 끄면 보존된 개별 설정을 다시 사용합니다.
- **알약 외곽선 자동·항상·없음:** 자동은 실제 배경과의 대비를 참고하고, 배경을 알 수 없을 때는 보수적으로 표시합니다. 오래된 배경 샘플을 무시하고 창이 숨겨지면 샘플링을 멈춥니다.
- **외곽 글로우**([#10](https://github.com/sampple-korea/dynamicisland/issues/10)): 은은한 외곽 빛과 강도 조절, 테마색 연동·개별 프리셋·HSV·HEX 색상, 음악의 앨범 색상 연동을 제공합니다. 저사양 모드에서는 설정값을 보존한 채 효과를 끕니다.
- **세로 전체 화면에서도 표시**([#14](https://github.com/sampple-korea/dynamicisland/issues/14)): 동작 설정에서 켜면 카메라처럼 상태 표시줄을 숨기는 세로 앱에서도 진행 중인 활동을 표시합니다. 잠금 화면·AOD 및 휴대폰 가로 모드의 숨김 규칙은 유지하며, 표시할 내용이 없으면 빈 아일랜드를 강제로 띄우지 않습니다.

### 녹화와 미디어 수정

- 알림 갱신·키 변경·시스템 타임스탬프 변화로 화면 녹화 시간이 초기화되는 문제와 세션 구분·호환성을 개선했습니다([#17](https://github.com/sampple-korea/dynamicisland/issues/17), 기여 [#19](https://github.com/sampple-korea/dynamicisland/pull/19)).
- 녹음 소유자와 생명주기 검사를 보강해 관계없는 세션·프로필을 진행 중인 녹음으로 잘못 판단하지 않도록 했습니다.
- 음악 앱 첫 실행 때 아일랜드가 잠깐 나타나는 현상을 줄이도록 포그라운드 감지를 개선했습니다. 오래된 제조사 캐시보다 실제 작업 상태를 우선하고, 불확실한 새 세션은 짧은 재확인 구간을 둡니다([#18](https://github.com/sampple-korea/dynamicisland/issues/18)).

### 언어와 검증

- 새 설정과 모듈 카드 문구를 **영어·한국어·일본어·중국어 간체·러시아어·터키어**로 제공합니다. 영어가 번역 원본이며 각 언어의 번역 문자열 **500/500개**를 확인했습니다. 6개 언어 README와 프로젝트 크레딧도 정리했습니다.
- 일반 테스트는 반복 검사를 정리한 **82개 핵심 검사**로 줄였고, 화면 검토용 이미지 생성은 `-Prender`로 분리했습니다. 로컬 안드로이드 검사·APK 빌드·번역 검사·번역 도구 테스트 2개가 통과했으며, 6개 언어의 실제 카드 렌더링을 검토했습니다. 배포 워크플로에서도 안드로이드 테스트 후 서명합니다.
- 개발 프리릴리즈입니다. 센서 값·USB 이어폰·전체 화면 오버레이·GPU 효과는 대상 기기에서 확인해야 합니다.

### 설치

기존 공식 배포 키로 서명하므로 이전 공식 릴리즈에서 업데이트할 수 있습니다. **별도 키로 서명한 로컬 테스트 APK를 설치했다면 필요한 설정을 보존한 뒤 삭제하고 이 공식 빌드를 설치해야 합니다.** 설치 후 SystemUI를 재시작하거나 재부팅하세요. 문제를 제보할 때는 **고급 설정 및 문제 해결 → 진단**을 함께 보내 주세요.
