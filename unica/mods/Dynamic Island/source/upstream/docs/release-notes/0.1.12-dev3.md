# Dynamic Island 0.1.12-dev3 · Test build: charging card

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.11.

## What's new

- **The charging card says "Charging" once.** It showed "Charging" as the title and again as the line under it. That line now begins with the percentage: "40%", or "54% · Super fast charging" when the charger is fast or wireless.
- **Installer progress shows on the island again.** Notifications in Android 16's ProgressStyle (for example an app installer's install progress) were left out of the progress cards on the assumption that another source shows them, but on One UI nobody did when One UI did not promote them. They are progress cards again, unless One UI promotes them or the live source already makes a card of them, so nothing shows twice. (Found by a reporter.)
- **New switch: Music player in the shade** (Display, on by default). Turn it off to keep the stock music player in the notification shade instead of the island's music card; nothing else in the shade changes. The lock screen shows the same player, so it follows the switch too. Reopen the shade after changing it.

## Install and notes

- Install over 0.1.11; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment, **not on a real device**.

## 한국어

0.1.11 위에 얹은 테스트용 프리릴리스입니다.

### 새로운 점

- **충전 카드가 "충전 중"을 한 번만 말합니다.** 제목과 그 아래 줄에 같은 "충전 중"이 두 번 나왔습니다. 이제 아래 줄은 퍼센트로 시작해서 "40%", 충전기가 빠르거나 무선이면 "54% · 초고속 충전"으로 나옵니다.
- **설치 앱의 진행 알림이 아일랜드에 다시 나옵니다.** Android 16의 ProgressStyle 알림(예: 설치 앱의 설치 진행)은 다른 곳이 보여 줄 거라고 보고 진행 카드에서 빼 두었는데, One UI가 라이브로 승격하지 않는 알림은 아무도 보여 주지 않았습니다. 이제 One UI가 승격했거나 라이브 소스가 이미 카드로 만든 것이 아니면 진행 카드가 되어서, 두 번 나오지 않습니다. (제보하신 분이 찾았습니다.)
- **새 스위치: 알림창의 음악 플레이어**(화면, 기본 켜짐). 끄면 알림창에 아일랜드의 음악 카드 대신 기본 음악 플레이어가 그대로 나옵니다. 알림창의 다른 것은 바뀌지 않습니다. 잠금화면이 같은 플레이어를 보여 주므로 스위치를 따라갑니다. 바꾼 뒤에는 알림창을 다시 열어 주세요.

### 설치와 참고
