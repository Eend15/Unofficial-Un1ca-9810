# Dynamic Island 0.1.11 · Smoother animations, Google sports and the flashlight

**English** · [한국어](#한국어)

Smoother opening, closing and shade animations, readable Google sports cards, one look for all live cards, and a flashlight card that works on more phones. Everything here was tried on real phones in the test builds 0.1.11-dev2 to dev14.

## What's new

- **The island goes and comes back smoothly with the notification shade.** As soon as you pull the shade down, a small dot next to the pill merges into it, the content shrinks and fades, the black body shrinks from the pill into a dot and the dot fades away. When the shade has nearly closed it all happens the other way round. It takes the same few frames whatever the speed of the shade, so there is no vanishing with a tick any more.
- **Closing the cards is clean.** While several cards close one after the other there is one pill instead of two, the card turns from grey glass to black gradually instead of flashing grey, the blur no longer drops out for a frame (also when another card slips into the hole), a card entering between others no longer flashes white, and the pill takes over from a folding card only after it has grown back to the card's size, so there is no pill inside a pill.
- **The blur no longer sticks out of the card corners.** It is rebuilt once the card's corner radius has settled, so it follows the card's shape.
- **All live cards look alike.** Progress-style live notifications (ride, delivery, ...) now use the same card as the other live cards: app name and time on top, the icon at the right, the bar under the text with its segments and marker. The old layout is kept only for message popups.
- **Google sports cards are readable.** The text of cards that show an app's own layout is judged by contrast against the dark card: colours that already stand out are kept, only hard-to-read ones are lightened (hue and transparency unchanged). The layout is also loaded with a dark theme, like System UI's shade does. The same rule is used for the shade cards.
- **Google sports matches show as separate cards in the shade.** System UI folded them into a grey stack when the Google app also posted a group summary (a "Sports from Google" heading). A group summary that is marked as a live notification is now left out of the shade list, so the matches come out as separate cards. The notification itself is not cancelled. (The idea and the fix come from the author of the original module.)
- **The flashlight card works on more phones.** Every camera with a flash is watched (a camera that cannot be read is skipped), and the card follows whichever one is switched on. A phone whose flashlight has a single brightness level gets the card as well, with *On* and a *Turn off* button instead of the slider (from a reporter's own fix). Phones whose System UI posts no live notification for the flashlight get it too, since the torch is read from the camera itself.
- **No double flashlight.** System UI's own flashlight notification is recognised on other builds of System UI too (by its tag or title), so it does not show next to the card, also when *All notifications in the island* is on.
- **New switch: Flashlight card** (on by default). Turn it off to get the plain "flashlight on" popup instead.

## Install and notes

- Install over 0.1.10 or any 0.1.11 test build; it is signed with the same key. Restart System UI afterwards.
- If something looks wrong, send a screen recording together with the report of **Tools → Diagnostics**.

## 한국어

알림창을 열고 닫을 때와 카드가 열리고 닫힐 때의 애니메이션이 더 부드러워지고, 구글 스포츠 카드의 글자가 읽히며, 모든 라이브 카드가 같은 모양이 되고, 손전등 카드가 더 많은 폰에서 나옵니다. 여기 있는 것은 모두 테스트 빌드 0.1.11-dev2~dev14로 실제 폰에서 써 본 것입니다.

### 새로운 점

- **알림창을 열고 닫을 때 아일랜드가 부드럽게 사라지고 돌아옵니다.** 알림창을 당기는 순간, 알약 옆의 작은 점이 알약에 합쳐지고, 내용이 작아지며 흐려지고, 검은 몸체가 알약에서 점으로 줄어든 뒤 점이 흐려집니다. 알림창이 거의 닫히면 그 반대로 진행됩니다. 알림창의 속도와 상관없이 같은 몇 프레임이 걸려서, 더 이상 틱 하고 사라지지 않습니다.
- **카드가 닫힐 때 깔끔합니다.** 여러 카드가 차례로 닫히는 동안 알약이 두 개로 보이지 않고, 카드가 회색으로 튀지 않고 회색 유리에서 검정으로 조금씩 바뀌며, 블러가 한 프레임 사라지지 않고(다른 카드가 홀에 들어갈 때도), 카드 사이로 들어오는 카드가 하얗게 번쩍이지 않으며, 알약이 카드 크기만큼 자란 뒤에만 접히는 카드에서 넘겨받아서 알약 안에 알약이 보이지 않습니다.
- **블러가 카드 모서리 밖으로 튀어나오지 않습니다.** 카드의 모서리 반경이 안정되면 블러를 한 번 다시 만들어서 카드 모양을 따라갑니다.
- **모든 라이브 카드가 같은 모양입니다.** 진행형(ProgressStyle) 라이브 알림(택시, 배달 등)도 다른 라이브 카드와 같은 카드를 씁니다: 위에 앱 이름과 시간, 오른쪽에 아이콘, 텍스트 아래에 구간과 마커가 있는 진행바. 예전 모양은 메시지 팝업에만 남았습니다.
- **구글 스포츠 카드의 글자가 읽힙니다.** 앱이 자기 화면을 그리는 카드의 글자색을 어두운 카드와의 대비로 판단해서, 이미 잘 보이는 색은 그대로 두고 읽기 어려운 색만 색조와 투명도를 유지한 채 밝게 합니다. 시스템 UI의 알림창처럼 다크 테마로 레이아웃을 불러오기도 합니다. 알림창 카드에도 같은 기준을 씁니다.
- **구글 스포츠 경기가 알림창에서 따로 카드로 나옵니다.** 구글 앱이 그룹 요약("Sports from Google" 제목)을 함께 올리면 시스템 UI가 경기를 회색 더미로 접어 버렸습니다. 라이브 알림으로 표시된 그룹 요약은 이제 알림창 목록에서 빼서, 경기가 각각 따로 카드로 나옵니다. 알림 자체를 취소하지는 않습니다. (아이디어와 수정은 원작 모듈 제작자가 알려 주었습니다.)
- **손전등 카드가 더 많은 폰에서 나옵니다.** 플래시가 있는 카메라를 전부 보고(읽을 수 없는 카메라는 건너뜁니다), 켜진 손전등이 있는 카메라를 따라갑니다. 손전등의 밝기 단계가 하나뿐인 폰도 슬라이더 대신 *켜짐*과 *끄기* 버튼이 있는 카드가 나옵니다(제보하신 분이 직접 고친 내용입니다). 시스템 UI가 손전등에 대한 라이브 알림을 올리지 않는 폰도 카메라에서 직접 읽으므로 카드가 나옵니다.
- **손전등이 두 번 나오지 않습니다.** 시스템 UI의 손전등 알림을 다른 빌드에서도(태그나 제목으로) 알아보고 카드 옆에 같이 나오지 않게 했습니다. *모든 알림을 아일랜드로*가 켜져 있어도 마찬가지입니다.
- **새 스위치: 손전등 카드**(기본 켜짐). 끄면 카드 대신 짧은 "손전등 켜짐" 팝업이 나옵니다.

### 설치와 참고
