# Dynamic Island 0.1.12-dev11 · Shade animation fixes

Source changes based on dev10, retaining its Turkish support and album-coloured waveform. No release is published with this push.

- The pill returns from the shade more slowly: spring response 0.34 → 0.46 seconds, with damping kept at 0.72. Its existing small bounce is now visible, with content, touch regions and status-bar coverage following the painted body. Extra growth is constrained at screen edges.
- The island window uses the status-bar sub-panel layer above the notification shade so a fast fling cannot cover the pill before its time-based shrink and fade finish. Its window context and reply window use the same type.
- Opacity remains bounded to 0–1. The restricted touch region, non-focusable island window and existing shrink-to-dot exit remain in place.
- The user confirmed the motion fixes on a device using the separate local dev10 test APK. That test APK predates integration with the remote Turkish/waveform changes; its version number was already used independently on the remote, so the combined source advances to dev11.
- Regression checks cover 60Hz/120Hz return timing, overshoot, interrupted return, edge bounds and touch/coverage, plus immediate full expansion with repeated callbacks using Canvas and surface opacity. The window-layer regression check fails with the old type. No change is made to unlock delay or expanded-card spring settings.

## 한국어

원격 dev10의 터키어 지원과 앨범 색상 파형을 유지한 소스 변경입니다. 이번 푸시에서는 릴리스를 게시하지 않습니다.

- 알림창을 닫으면 알약이 더 여유 있게 돌아옵니다. 스프링 응답값은 0.34초에서 0.46초로 늘리고 감쇠비는 0.72로 유지합니다. 기존의 작은 반동을 보여 주고, 내용·터치·상태바 가림 영역이 보이는 몸체를 따릅니다. 화면 가장자리에서는 추가 성장을 제한합니다.
- 빠르게 내린 알림창이 축소·페이드 도중 알약을 먼저 덮지 않도록 아일랜드 창을 알림창 위의 상태바 서브 패널 층으로 옮깁니다. 창 컨텍스트와 답장 창에도 같은 창 유형을 적용합니다.
- 투명도는 0~1 범위를 지킵니다. 제한된 터치 영역, 포커스를 가져가지 않는 아일랜드 창과 점으로 줄어든 뒤 사라지는 동작을 유지합니다.
- 별도로 전달한 로컬 dev10 테스트 APK에서 사용자가 애니메이션 수정을 기기로 확인했습니다. 해당 APK에는 이후 통합한 원격 터키어·파형 변경이 없으며, 원격에서 같은 버전 번호를 이미 사용해 통합 소스 버전은 dev11로 올립니다.
- 60Hz·120Hz의 복귀 타이밍·반동, 복귀 중 재진입, 가장자리·터치·가림 영역과 즉시 완전 펼침·반복 콜백을 Canvas·서피스 투명도 양쪽 경로로 검사합니다. 창 층 회귀 검사는 기존 창 유형에서 실패합니다. 잠금 해제 지연과 펼친 카드의 스프링 설정은 바꾸지 않습니다.
