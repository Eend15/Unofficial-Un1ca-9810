# Dynamic Island 0.1.1 · English rules

**English** · [한국어](#한국어)

This release adds rules for English-language apps and keeps everything else of 0.1.0.

## What's new

- **English rules** for the cards made from rules, written for this project from how English-language apps word their notifications (no LiveBridge file is copied):
  - **Food delivery:** DoorDash, Uber Eats, Grubhub, Postmates, Instacart, Domino's, Pizza Hut, Starbucks, Chipotle, Deliveroo, Just Eat, Wolt, Glovo and others: order placed, preparing, on the way, arriving, delivered.
  - **Parcels:** Amazon, UPS, FedEx, USPS, DHL, Royal Mail, Shop, Evri, Canada Post, Australia Post and others: label created, in transit, at the local facility, out for delivery, delivered.
  - **Ride hailing:** Uber, Lyft, Bolt, Grab, Ola, DiDi, FREE NOW, Cabify, inDrive: finding a driver, driver assigned, on the way, arrived, trip complete.
  - **Navigation:** Google Maps, Waze, Citymapper, HERE, TomTom, MapQuest and others: turns with the distance in miles, feet or kilometres, getting off, arrival.
  - **Accessories:** connection, disconnection, fully charged and low-battery percentages for Pixel Buds, Fitbit, Garmin, Galaxy Wearable and other accessory apps.
  - Chat, mail, social, video and news apps never make a card. Promotions, review requests, tips and refunds are ignored.
- **Stage names in your language:** English phones show English stage names, Korean phones Korean ones. A stage name you set in the rule manager applies to both.
- README pictures of the island and the settings app on a mock phone.

## Install and notes

- Install the APK over 0.1.0; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

이번 버전은 영어권 앱 규칙을 추가했고, 0.1.0의 나머지 기능은 그대로입니다.

### 새로운 점

- **영어 규칙:** 규칙으로 만드는 카드에 영어권 앱 규칙이 추가되었습니다. 영어권 앱이 알림 문구를 쓰는 방식을 보고 이 프로젝트를 위해 새로 썼으며 LiveBridge 파일을 복사하지 않았습니다.
  - **음식 배달:** DoorDash, Uber Eats, Grubhub, Postmates, Instacart, 도미노피자, 피자헛, 스타벅스, 치폴레, Deliveroo, Just Eat, Wolt, Glovo 등: 주문, 준비 중, 배달 중, 곧 도착, 배달 완료.
  - **택배:** 아마존, UPS, FedEx, USPS, DHL, Royal Mail, Shop, Evri, Canada Post, Australia Post 등: 송장 생성, 이동 중, 지역 터미널 도착, 배송 출발, 배송 완료.
  - **차량 호출:** Uber, Lyft, Bolt, Grab, Ola, DiDi, FREE NOW, Cabify, inDrive: 기사 찾는 중, 배차, 이동 중, 도착, 운행 완료.
  - **길안내:** 구글 지도, Waze, Citymapper, HERE, TomTom, MapQuest 등: 마일·피트·킬로미터 거리가 표시되는 회전 안내, 하차, 도착.
  - **액세서리:** Pixel Buds, Fitbit, Garmin, Galaxy Wearable 등의 연결·연결 해제, 충전 완료, 배터리 부족 퍼센트.
  - 채팅, 메일, 소셜, 동영상, 뉴스 앱은 카드로 만들지 않고, 광고·리뷰 요청·팁·환불 알림은 무시합니다.
- **내 언어로 나오는 단계 이름:** 영어 폰에서는 영어, 한국어 폰에서는 한국어 단계 이름이 나옵니다. 규칙 관리에서 직접 붙인 단계 이름은 두 언어에 모두 적용됩니다.
- README에 가상의 폰 위에 그린 아일랜드와 설정 앱 스크린샷을 넣었습니다.
