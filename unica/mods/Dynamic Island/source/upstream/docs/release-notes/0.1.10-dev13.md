# Dynamic Island 0.1.10-dev13 · Test build

**English** · [한국어](#한국어)

A pre-release for testing. It follows 0.1.10-dev3 and collects the fixes made since.

## What's new

- **Flashlight card, redesigned.** One bar with the flashlight icon at its start and the percentage at its end; a small *Flashlight* label and a round power button on top replace the old two-line header and the wide *Turn off* button. The yellow disc is gone.
- **Notification icons make way.** When the island is moved over the notification icons in the status bar, they slide aside instead of disappearing; only what no longer fits before the system icons fades out.
- **Screen recording card without the chip.** On phones where System UI does not report the recording as a chip, the recorder's own notification becomes the recording card, with its timer and stop button.
- **Switches are enforced.** What a switch turns off (charging and low battery, sound mode, Bluetooth, setting changes, camera and microphone, downloads) is dropped just before the island is drawn, whichever way it was created, and the island follows a switch at once. The *Downloads & transfers* switch now also covers downloads that apps post as One UI live notifications.
- **Settings reach System UI another way too.** If System UI cannot read the settings file, it asks the app (the Diagnostics line `settings source` says which way is used).
- **Live notification cards keep their text readable.** Cards that show an app's own layout (such as Google sports) stay dark like the other cards, and the app's dark text is lightened so that it can be read on them.
- **Nothing OS (not verified on a device):** see 0.1.10-dev3.

## Install and notes

- Install over 0.1.9 or 0.1.10-dev3; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

테스트용 프리릴리스입니다. 0.1.10-dev3 이후에 고친 것을 모았습니다.

### 새로운 점

- **손전등 카드 새 디자인.** 막대 하나에 시작 쪽 손전등 아이콘, 끝 쪽 퍼센트가 들어갑니다. 위에는 작은 *손전등* 라벨과 둥근 전원 버튼이 있고, 예전의 두 줄 머리글과 넓은 *끄기* 버튼은 없어졌습니다. 노란 원도 없앴습니다.
- **알림 아이콘이 비켜 줍니다.** 아일랜드를 상태바의 알림 아이콘 위로 옮기면 아이콘이 사라지지 않고 옆으로 밀립니다. 시스템 아이콘 앞에 더는 들어가지 않는 것만 서서히 사라집니다.
- **칩이 없어도 화면 녹화 카드.** 시스템 UI가 녹화를 칩으로 알려 주지 않는 기기에서는 녹화기의 알림이 타이머와 중지 버튼이 있는 녹화 카드가 됩니다.
- **스위치가 확실히 적용됩니다.** 스위치로 끈 것(충전·배터리 부족, 소리 모드, 블루투스, 설정 변경, 카메라·마이크, 다운로드)은 어느 경로로 만들어졌든 아일랜드를 그리기 직전에 걸러지고, 스위치를 바꾸면 곧바로 반영됩니다. *다운로드 및 전송* 스위치는 앱이 One UI 라이브 알림으로 올리는 다운로드도 다룹니다.
- **설정이 시스템 UI에 닿는 길이 하나 더 생겼습니다.** 시스템 UI가 설정 파일을 읽지 못하면 앱에 직접 묻습니다(진단의 `settings source` 줄에 어느 쪽을 쓰는지 나옵니다).
- **라이브 알림 카드의 글자가 읽힙니다.** 앱이 자기 화면을 그리는 카드(구글 스포츠 등)도 다른 카드처럼 어둡게 유지하고, 앱의 어두운 글자는 밝게 바꿔 읽히게 했습니다.
- **Nothing OS(실기기 검증 전):** 0.1.10-dev3 설명을 참고하세요.

### 설치와 참고

- 0.1.9나 0.1.10-dev3 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 검증했고 **실제 기기에서는 검증하지 못했습니다.** 동작하지 않으면 **도구 → 진단**의 리포트를 복사해 이슈와 함께 보내 주세요.
