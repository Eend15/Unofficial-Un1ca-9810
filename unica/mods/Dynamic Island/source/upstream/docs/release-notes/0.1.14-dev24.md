# Dynamic Island 0.1.14-dev24 · Expanding-beam flashlight

**Development pre-release** · Changes since **0.1.13** · **English** / [한국어](#한국어)

## Optional flashlight controls (#4)

- **System events → Flashlight controls → Expanding beam** enables the new design. **Classic slider remains the default**; saved selections are preserved. All six supported languages include this option and its search entry.
- Tap the flashlight graphic to turn it on or off. Drag the curved control horizontally to change the phone's supported brightness levels. Light reaches the control and fades beyond it; the minimum position sits closer to the lens.
- The white beam includes soft scattering and subtle colour separation. The last 15% of travel sharply opens the **far end**, while the emitting aperture stays narrow. Light remains inside the card.
- The curved thumb follows a small resisted vertical drag and returns smoothly to the centre on release or cancellation. Horizontal brightness control remains independent; rebuilding the card during a brightness update preserves the spring.
- The beam-style power button ramps supported hardware brightness over approximately **240 ms**. The chosen brightness is separate from temporary transition levels: a selected level 4 powers down through 3 → 2 → 1 → off, then powers back up through 1 → 2 → 3 → 4. Intermediate writes do not use Samsung's saved-brightness setting. Direct slider changes keep the existing save behaviour.
- After the card's button turns the light off, its expanded controls remain for **five seconds** so it can be turned back on. Earlier automatic-collapse timeouts wait; manual dismissal still closes immediately. Reversing the transition, changing the slider, losing camera access or an external off cancels obsolete writes. Single-level torches keep binary hardware power with the visual fade.

## Other changes already on main

- **Settings search:** ranked results use translated labels and descriptions, related terms, Korean initials and bounded typo matching. Selecting a result opens the existing setting.
- **Card material:** Classic remains the default. Frosted material is an opt-in experiment, including captured-backdrop rendering, curved panel lighting and album-colour treatment. Shade clipping and transition handling have also been revised; this remains development work.
- **Quick-panel performance:** opening or dragging the system quick panel no longer repeatedly restores and reinstalls unrelated notification cards. A hidden compact pill stops requesting unnecessary frames. This addresses confirmed extra work; the reported long-session slowdown still needs device confirmation.
- **WhatsApp call timers:** wait for notification connection evidence instead of starting from ringing/dialling timestamps. This is a candidate fix for #23; confirmation with the reporting device is still welcome.

## Validation and installation

- **126 default Android tests**, translation-tool tests and the release APK build pass locally. Each of English, Korean, Japanese, Simplified Chinese, Russian and Turkish contains **570/570** translated strings. The release workflow repeats validation before signing.
- Optical layout and gesture tuning incorporate maintainer device feedback from local builds. Power-ramp timing, saved-brightness behaviour and compatibility across devices still require testing with this package.
- The official APK uses the existing project release key. **A separately signed local test APK must be uninstalled before installing the official release; preserve any settings you need first.** Existing official releases can be updated normally. Restart SystemUI or reboot after installation.

## 한국어

**0.1.13 이후 변경사항**을 담은 개발 프리릴리즈입니다.

### 선택형 손전등 조작 UI (#4)

- **시스템 이벤트 → 손전등 조작 방식 → 넓어지는 빛**에서 새 UI를 선택합니다. **기본값은 기존 슬라이더**이며 저장한 선택은 유지합니다. 지원 언어 6개와 설정 검색에 반영했습니다.
- 손전등 그림을 누르면 켜거나 끄고, 곡선 막대를 좌우로 당기면 실제 지원 밝기 단계를 조절합니다. 빛은 막대 위치까지 이어진 뒤 부드럽게 흐려지며, 최소 위치는 렌즈 쪽으로 더 가까이 줄어듭니다.
- 흰 중심광에 부드러운 산란과 옅은 색 분리를 더했습니다. 마지막 약 15%에서 **나오는 부분은 좁게 유지하고 반대쪽 끝만 크게 벌어집니다.** 효과는 카드 안에 유지됩니다.
- 곡선 막대는 상하 이동을 조금 따라가며 저항을 받고, 손을 놓거나 취소하면 중앙으로 부드럽게 돌아옵니다. 상하 움직임은 밝기를 바꾸지 않으며, 밝기 알림으로 카드가 갱신돼도 탄성이 이어집니다.
- 새 UI의 전원 버튼은 실제 지원 밝기를 약 **240ms** 동안 단계적으로 바꿉니다. 선택 밝기와 전환용 임시 밝기를 분리해, 4단계에서 끄면 3 → 2 → 1 → 꺼짐, 다시 켜면 1 → 2 → 3 → 4로 복원합니다. 중간 단계는 삼성의 저장 밝기 설정을 변경하는 경로를 사용하지 않고, 슬라이더로 직접 고른 밝기는 기존처럼 저장합니다.
- 버튼으로 끈 뒤 펼쳐진 조작 패널을 **5초간 유지**해 다시 켤 수 있습니다. 자동 축소가 먼저 실행돼도 기다리며, 직접 닫으면 바로 닫힙니다. 도중에 반대로 누르거나 슬라이더를 조절하거나 외부에서 끄거나 카메라 접근이 중단되면 이전 예약을 취소합니다. 밝기 단계가 하나인 기기는 실제 전원을 켜고 끄는 동작과 화면 페이드를 사용합니다.

### main에 반영되어 있던 변경사항

- **설정 검색:** 번역된 이름·설명, 관련 표현, 한글 초성과 제한된 오타 보정을 이용해 결과를 정렬하고 기존 설정으로 이동합니다.
- **카드 재질:** 기본값은 클래식입니다. 프로스티드 재질은 선택형 실험 기능이며, 배경 캡처·패널 굴곡과 가장자리 조명·앨범 색 반영을 포함합니다. 알림창 잘림과 전환 처리도 수정했으며 계속 개발 중입니다.
- **퀵패널 성능:** 시스템 퀵패널을 열거나 당길 때 관련 없는 알림 카드를 반복해서 복원·재설치하던 작업을 제거했습니다. 숨은 작은 알약도 불필요한 프레임 요청을 멈춥니다. 확인된 추가 작업을 줄인 수정이며, 장시간 사용 후 느려진다는 보고는 기기 확인이 더 필요합니다.
- **WhatsApp 통화 시간:** 벨소리·발신 대기 시각 대신 알림의 통화 연결 근거를 기다리도록 바꿨습니다. #23의 의심 지점을 수정한 것으로, 제보 기기의 추가 확인은 여전히 환영합니다.
