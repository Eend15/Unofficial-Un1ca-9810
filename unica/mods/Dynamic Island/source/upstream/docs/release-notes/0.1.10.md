# Dynamic Island 0.1.10 · Notifications, replies and Nothing OS

**English** · [한국어](#한국어)

Notification popups got much better (they no longer block your touches, can be answered from the island and are replaced by newer ones), the switches in the settings now really switch things off, and the first support for Nothing OS is here.

## What's new

- **Notifications on the island.**
  - A popup no longer closes when you touch elsewhere (typing keeps working), a swipe up closes it at once, and it leaves without being kept as a small pill. A newer notification replaces the one that is open.
  - **Reply from the island.** The *Reply* button opens a text field with a send button above the keyboard; the card stays open while you type. Apps that offer the reply only for watches (the Samsung messages app) work too.
  - **All notifications in the island** (new switch, *experimental*): every new notification gets a card, also quiet ones. It may not work on every phone or for every app.
  - On One UI 9 the stock banner is also taken away when notifications come in a row, and the island removes the stock heads-up entry it took over.
- **Switches are enforced.** What a switch turns off (charging and low battery, sound mode, Bluetooth, setting changes, camera and microphone, downloads) is dropped just before the island is drawn, and the island follows a switch at once. *Downloads & transfers* now also covers downloads that apps post as One UI live notifications. If System UI cannot read the settings file it asks the app (Diagnostics: `settings source`).
- **Flashlight card, redesigned.** One bar with the icon at its start and the percentage at its end, a *Flashlight* label and a round power button on top.
- **Screen recording card without the chip.** On phones where System UI does not report the recording as a chip, the recorder's own notification becomes the card, with its timer and a **Stop** button.
- **Status bar icons slide aside** when the island is moved over them, instead of disappearing; icons no longer stay half transparent after a notification.
- **Live notification cards stay readable.** Cards that show an app's own layout (for example Google sports) stay dark like the others, and the app's dark text is lightened.
- **New option: coloured icons in the small island.** Keep the real colours of an app icon or a team logo when the island is small (off by default: grey).
- **Closing animation.** The content of the cards fades first, the empty shape then folds into the pill in one motion, and no dark smear stays behind.
- **Nothing OS (first support, lowest priority, not verified on a device).** The stock chips for calls, screen recording, sharing and casting no longer sit next to the island, and Android 16 live notifications become island cards.
- **One UI 8.0.** The stock music capsule in the status bar is kept away on this build too.

## Install and notes

- Install over 0.1.9; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

알림 팝업이 훨씬 좋아졌고(터치를 막지 않고, 아일랜드에서 바로 답장할 수 있고, 새 알림이 오면 바뀝니다), 설정의 스위치가 실제로 적용되며, Nothing OS를 처음 지원합니다.

### 새로운 점

- **아일랜드의 알림.**
  - 팝업은 다른 곳을 터치해도 닫히지 않고(타자 입력이 그대로 됩니다), 위로 쓸면 바로 닫히며, 작은 알약으로 남지 않고 사라집니다. 새 알림이 오면 열려 있던 팝업이 새 알림으로 바뀝니다.
  - **아일랜드에서 답장.** *답장* 버튼을 누르면 키보드 위에 입력창과 전송 버튼이 열리고, 입력하는 동안 카드가 닫히지 않습니다. 시계용으로만 답장을 주는 앱(삼성 메시지)도 됩니다.
  - **모든 알림을 아일랜드로**(새 스위치, *실험 기능*): 조용한 알림까지 새 알림마다 카드를 띄웁니다. 기기나 앱에 따라 잘 작동하지 않을 수 있습니다.
  - One UI 9에서 알림이 연달아 올 때도 기본 배너를 치우고, 아일랜드가 가져간 알림의 기본 배너 항목은 제거합니다.
- **스위치가 확실히 적용됩니다.** 스위치로 끈 것(충전·배터리 부족, 소리 모드, 블루투스, 설정 변경, 카메라·마이크, 다운로드)은 아일랜드를 그리기 직전에 걸러지고, 스위치를 바꾸면 곧바로 반영됩니다. *다운로드 및 전송*은 앱이 One UI 라이브 알림으로 올리는 다운로드도 다룹니다. 시스템 UI가 설정 파일을 읽지 못하면 앱에 직접 묻습니다(진단의 `settings source`).
- **손전등 카드 새 디자인.** 막대 하나에 시작 쪽 아이콘, 끝 쪽 퍼센트, 위에는 *손전등* 라벨과 둥근 전원 버튼이 있습니다.
- **칩이 없어도 화면 녹화 카드.** 시스템 UI가 녹화를 칩으로 알려 주지 않는 기기에서는 녹화기의 알림이 타이머와 **중지** 버튼이 있는 카드가 됩니다.
- **상태바 아이콘이 비켜 줍니다.** 아일랜드를 아이콘 위로 옮기면 아이콘이 사라지지 않고 옆으로 밀립니다. 알림 뒤에 아이콘이 반투명하게 남던 문제도 고쳤습니다.
- **라이브 알림 카드의 글자가 읽힙니다.** 앱이 자기 화면을 그리는 카드(구글 스포츠 등)도 다른 카드처럼 어둡게 유지하고, 앱의 어두운 글자는 밝게 바꿉니다.
- **새 옵션: 작은 아일랜드에서 아이콘 색 유지.** 아일랜드가 작아졌을 때 앱 아이콘이나 팀 로고의 원래 색을 보여 줍니다(기본은 꺼짐: 회색).
- **닫히는 애니메이션.** 카드의 내용이 먼저 사라진 뒤 빈 모양이 한 동작으로 알약에 접혀 들어가고, 어두운 얼룩이 남지 않습니다.
- **Nothing OS(첫 지원, 가장 낮은 우선순위, 실기기 검증 전).** 통화·화면 녹화·공유·캐스트용 기본 칩이 아일랜드 옆에 남지 않고, Android 16 라이브 알림은 아일랜드 카드가 됩니다.
- **One UI 8.0.** 이 빌드에서도 상태바의 기본 음악 캡슐을 치웁니다.
