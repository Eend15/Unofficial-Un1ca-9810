# Dynamic Island 0.1.6 · Smoother cards, themed lock screen player, sturdier rules

**English** · [한국어](#한국어)

A polish release: the cards open and close more smoothly, the music player on the lock screen wears the island's look, and the rules read more notifications correctly.

## What's new

- **The cards open and close with their content.** Before, a card grew as an empty black shape and its content appeared only at the end; closing was the same in reverse, with the content vanishing first. Now the content grows with the card as it opens and shrinks with it as it folds back into the island, and only melts away at the very end.
- **Smoother glass.** The card used to turn see-through in one jump near the end of opening (and the other way round when closing). It now becomes transparent gradually over the whole movement.
- **The island's music player on the lock screen.** The player in the notification panel is no longer swapped back to the stock one on the lock screen: the buttons and the seek bar work there. Tapping the card itself opens the app only after you unlock.
- **A stopped song keeps its look.** When the music stops or the player ends but its player is still in the notification panel, it keeps the island's look instead of falling back to the stock player.
- **Animation settings.** The comparison at the top of the Animation page now really moves, and exaggerates the difference so it is easy to see.
- **A new built-in rule:** the "Processing… processing the assistant's request" notification becomes a card, from any app.
- **Rules.**
  - A battery card says "low battery" only for 20 % and below; "battery 85 %" is no longer a low-battery card.
  - "Disconnected" and "isn't connected" are no longer read as connected, and "discharged" is no longer read as fully charged.
  - Distances such as "0.5 miles" or "12 min" were cut to "0.5 m" and "12 m"; they are read correctly now.
  - After you edit a rule, the cards already on the island follow it within a few seconds instead of waiting for the next notification.
  - A rule whose name has capital letters can be reset again. A broken rule file you import can no longer crash the rule list. The card colour you type is checked properly (`#RRGGBB`). A rule with stages beyond its stated last stage now counts them.
- **Settings.** Turning the phone no longer sends you back to the first page, and the animation choice you have not applied yet is kept when you leave the app and come back.
- **Steadier and lighter.** While the stack of cards is open the island no longer redraws every frame when nothing moves, so it uses less battery. A card that is dismissed while you hold it no longer reacts to your tap. The island no longer pops up over the lock screen or a full-screen app when it should stay hidden, and one failed frame no longer freezes the animations.

## Install and notes

- Install the APK over 0.1.5; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

카드가 더 부드럽게 열리고 닫히고, 잠금화면의 음악 플레이어에도 아일랜드의 모습이 적용되며, 규칙이 알림을 더 정확하게 읽는 다듬기 버전입니다.

### 새로운 점

- **카드가 내용과 함께 열리고 닫힙니다.** 전에는 카드가 빈 검은 모양으로 먼저 커지고 내용은 끝에 가서야 나타났습니다. 닫을 때도 반대로 내용이 먼저 사라졌습니다. 이제 열릴 때는 내용이 카드와 같이 커지고, 아일랜드로 접힐 때는 같이 작아지다가 맨 끝에서만 스르르 사라집니다.
- **더 부드러운 유리 질감.** 카드가 열리는 끝에서 갑자기 투명해지던(닫을 때는 반대로) 것을 고쳤습니다. 이제 움직이는 내내 서서히 투명해집니다.
- **잠금화면에서도 아일랜드 음악 플레이어.** 알림창의 플레이어가 잠금화면에서는 기본 플레이어로 돌아가던 것을 없앴습니다. 버튼과 재생 막대가 잠금화면에서도 동작합니다. 카드 본문을 눌러 앱을 여는 것은 잠금을 푼 뒤에 됩니다.
- **멈춘 곡도 모습 유지.** 음악이 멈추거나 플레이어가 끝났는데 알림창에 플레이어가 남아 있을 때, 기본 플레이어로 돌아가지 않고 아일랜드의 모습을 유지합니다.
- **애니메이션 설정.** 애니메이션 화면 맨 위의 비교가 실제로 움직이고, 차이가 잘 보이도록 과장해서 보여 줍니다.
- **새 기본 규칙:** "처리하는 중… 어시스턴트의 요청을 처리하는 중" 알림이 어느 앱이든 카드가 됩니다.
- **규칙.**
  - 배터리 카드는 20% 이하일 때만 "배터리 부족"으로 나옵니다. "배터리 85%"는 더 이상 배터리 부족 카드가 되지 않습니다.
  - "연결 해제됨", "연결되지 않음"을 연결됨으로, "방전됨"을 충전 완료로 읽던 것을 고쳤습니다.
  - "0.5 miles", "12 min" 같은 거리가 "0.5 m", "12 m"로 잘리던 것을 고쳤습니다.
  - 규칙을 고치면 이미 떠 있는 카드가 다음 알림을 기다리지 않고 몇 초 안에 따라옵니다.
  - 이름에 대문자가 있는 규칙도 다시 되돌릴 수 있습니다. 잘못된 규칙 파일을 가져와도 규칙 목록이 더 이상 죽지 않습니다. 카드 색 입력(`#RRGGBB`)을 제대로 확인합니다. 마지막 단계보다 높은 단계를 가진 규칙은 그 단계까지 셉니다.
- **설정.** 화면을 돌려도 첫 화면으로 돌아가지 않고, 아직 적용하지 않은 애니메이션 선택은 다른 앱에 갔다 와도 유지됩니다.
- **더 안정적이고 가볍게.** 카드 스택을 펼친 동안 움직이는 것이 없어도 매 프레임 다시 그리던 것을 멈춰 배터리를 덜 씁니다. 누르고 있는 동안 지워진 카드가 탭에 반응하지 않습니다. 숨겨야 할 때 잠금화면이나 전체화면 앱 위에 아일랜드가 나타나던 것을 막았고, 한 프레임이 실패해도 애니메이션이 멈추지 않습니다.
