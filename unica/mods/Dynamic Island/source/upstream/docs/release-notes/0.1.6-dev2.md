# Dynamic Island 0.1.6-dev2 (pre-release)

**English** · [한국어](#한국어)

A test build on top of 0.1.6. It is a pre-release: install it only if you want to try the newest changes.

## What changed since 0.1.6

- **Screen recording.** While the screen is being recorded, the recorder's own "tap here to stop recording" notification is hidden from the notification panel, since the island already shows the recording card. This follows the *hide original notifications* setting.
- **Music glow.** On a track change the glow behind the music card no longer flickers in brightness: the old colours now fade out completely as the new ones come in, and a player that reports "skipping to next" no longer dims the glow for a moment.

## Install and notes

- Install over 0.1.6; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

0.1.6 위에 얹은 테스트 빌드입니다. 사전 릴리스이니 가장 새로운 변경을 써 보고 싶을 때만 설치하세요.

### 0.1.6 이후 바뀐 점

- **화면 녹화.** 화면을 녹화하는 동안 녹화기가 띄우는 "녹화를 중지하려면 여기를 누르세요" 알림이 알림창에서 숨겨집니다. 아일랜드에 이미 녹화 카드가 있기 때문입니다. **원본 알림 숨기기** 설정을 따릅니다.
- **음악 글로우.** 다음 곡으로 넘어갈 때 음악 카드 뒤 글로우의 밝기가 끊기던 것을 고쳤습니다. 이전 색이 새 색과 교차하며 완전히 사라지고, "다음 곡으로 이동 중"을 알리는 플레이어에서 글로우가 잠깐 어두워지지 않습니다.

### 설치와 참고

- 0.1.6 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 검증했고 **실제 기기에서는 검증하지 못했습니다.** 동작하지 않으면 **도구 → 진단**의 리포트를 복사해 이슈와 함께 보내 주세요.
