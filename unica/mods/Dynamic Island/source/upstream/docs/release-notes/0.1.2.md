# Dynamic Island 0.1.2 · New icon and bug fixes

**English** · [한국어](#한국어)

This release has a new app icon, a more detailed diagnostics report and a round of bug fixes found by reading the whole code base.

## What's new

- **New app icon:** a black island over two stacked cards, as an adaptive icon with a themed (monochrome) layer.
- **More detailed diagnostics:** the report now shows which apk the module was loaded from, whether the settings file is readable, the settings in effect and the last 60 events (items added or removed, the island hidden or shown and why, shade cards installed or given up, setting changes). Open **Tools → Diagnostics**.

## Fixes

- **Shade cards:** after System UI rebuilt a row, the old card stayed behind next to the new stock views, so text could be drawn twice on top of itself. The old card is now removed and a fresh one is bound. A failure while measuring no longer upsets the height limits of the enclosing measure.
- **Haptics:** the haptics switch now also covers expanding the island, button presses, swipe confirmation, finishing a seek and taps on shade cards. Before, only some of them followed it.
- **Refresh timers:** every source shared one refresh timer, so one source could cancel another's. A charging notice or a paused player could then stay on the island longer than intended. Each source now has its own.
- **English rules:** "disconnected" and "not connected" are no longer read as connected, "picked up" is no longer read as delivered, and words such as "moderate" or "details" no longer trip the navigation rule.
- **Korean rules:** "배송이 완료되었습니다" is recognised as delivered.
- **Rules:** a status that is posted again, or whose tap target changes, now renews the card instead of keeping the old expiry and intent.
- **Island:** a card that is leaving no longer flashes back on every update; the seek bar keeps following the finger when the list refreshes; a card no longer stays forever after a rotation or fold; the score of a sports card is drawn once; opening the stack again no longer flashes the old pill content; a button tap hits the button that was pressed.
- **Touch:** a second finger no longer moves the gesture; very long notification text is cut before it is laid out.
- **Events:** a hotspot that is already on at start-up is recognised, and battery updates work for several Bluetooth devices at once.
- **Start-up and safety:** the island window is created again on the next refresh if adding it failed; settings are read before the first use; the crash guard only counts crashes that involve this module; the app picker no longer crashes when the screen is rotated while it loads.

## Install and notes

- Install the APK over 0.1.1; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

이번 버전은 새 앱 아이콘, 더 자세한 진단 리포트, 전체 코드를 읽으며 찾은 버그 수정을 담았습니다.

### 새로운 점

- **새 앱 아이콘:** 카드 두 장이 겹쳐 있는 위에 검은 아일랜드가 있는 어댑티브 아이콘이며, 테마 아이콘(단색) 레이어도 있습니다.
- **더 자세한 진단:** 리포트에 모듈이 로드된 apk, 설정 파일을 읽을 수 있는지, 적용 중인 설정, 최근 이벤트 60개(항목 추가·제거, 아일랜드 숨김·표시와 사유, 알림창 카드 설치·포기, 설정 변경)가 나옵니다. **도구 → 진단**에서 볼 수 있습니다.

### 수정

- **알림창 카드:** SystemUI가 행을 다시 만들면 이전 카드가 새 기본 뷰 옆에 남아 글자가 겹쳐 그려질 수 있었습니다. 이제 이전 카드를 떼고 새 카드를 다시 붙입니다. 높이 측정 중 실패해도 바깥 측정의 높이 제한이 틀어지지 않습니다.
- **햅틱:** 햅틱 스위치가 아일랜드 펼침, 버튼 누름, 스와이프 확정, 탐색 완료, 알림창 카드 탭에도 적용됩니다. 전에는 일부만 따랐습니다.
- **갱신 타이머:** 모든 소스가 갱신 타이머 하나를 같이 써서 한 소스가 다른 소스의 예약을 취소할 수 있었습니다. 충전 안내나 일시정지된 플레이어가 의도보다 오래 남을 수 있었고, 이제 소스마다 따로 가집니다.
- **영어 규칙:** "disconnected", "not connected"를 연결됨으로, "picked up"을 배달 완료로 읽지 않고, "moderate", "details" 같은 단어에 길안내 규칙이 걸리지 않습니다.
- **한국어 규칙:** "배송이 완료되었습니다"를 배송 완료로 인식합니다.
- **규칙:** 같은 상태가 다시 올라오거나 누르는 대상이 바뀌면 이전 만료 시간과 인텐트를 유지하지 않고 카드를 새로 만듭니다.
- **아일랜드:** 사라지는 카드가 갱신 때마다 깜빡이지 않고, 갱신돼도 탐색 막대가 손가락을 따라가고, 회전·접힘 뒤에 카드가 영원히 남지 않으며, 스포츠 카드의 점수가 한 번만 그려지고, 열린 스택을 다시 펼쳐도 예전 알약 내용이 깜빡이지 않고, 버튼을 누르면 눌러 둔 버튼이 실행됩니다.
- **터치:** 두 번째 손가락이 제스처를 움직이지 않고, 아주 긴 알림 텍스트는 레이아웃 전에 잘라 냅니다.
- **이벤트:** 시작할 때 이미 켜져 있던 핫스팟을 인식하고, 블루투스 기기 여러 개의 배터리 갱신이 동시에 됩니다.
- **시작과 안전:** 아일랜드 창을 만드는 데 실패하면 다음 갱신에서 다시 시도하고, 첫 사용 전에 설정을 읽어 두며, 크래시 가드는 이 모듈이 관련된 크래시만 세고, 앱 선택 창이 불러오는 중에 화면을 돌려도 크래시하지 않습니다.
