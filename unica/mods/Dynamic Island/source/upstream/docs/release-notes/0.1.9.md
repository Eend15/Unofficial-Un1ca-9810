# Dynamic Island 0.1.9 · The size of the island

**English** · [한국어](#한국어)

The island's size can now be set, with the same live preview as its position.

## What's new

- **Island size.** The settings page is now **Island position and size**. A new *Island size* group sets the pill's **height** (-20 % to +40 %; its icons grow with it), the **narrowest** it ever gets (so even a tiny item shows a wide pill) and the **widest** it ever gets (so a long text stops there). A switch, *Keep the widest width*, stops the island from shrinking again after it has grown, until it hides.
- **Live, on the real status bar.** The island on the real status bar follows the sliders as you drag them. While you set the widest width the sample item holds a long text, so you can see the pill grow to that width; for the narrowest it holds a short one.
- **The two widths can not cross.** The narrowest stops at the widest, and the widest stops at the narrowest. The narrowest now goes up to 420 dp.
- **Fixed:** the narrowest width and the bigger icons of a higher pill were not applied to the pill on screen; now they are.
- *Reset the position* also puts the size back.

## Install and notes

- Install over 0.1.8; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

아일랜드의 크기를 정할 수 있게 됐고, 위치와 같은 실시간 미리보기를 씁니다.

### 새로운 점

- **아일랜드 크기.** 설정 페이지 이름이 **아일랜드 위치와 크기**로 바뀌었습니다. 새 *아일랜드 크기* 그룹에서 알약의 **높이**(-20%~+40%, 아이콘도 같이 커집니다), 가장 좁아지는 **최소 너비**(아주 작은 항목도 넓은 알약으로 보입니다), 가장 넓어지는 **최대 너비**(긴 글이 거기서 멈춥니다)를 정합니다. *가장 넓어진 너비 유지* 스위치를 켜면 한 번 넓어진 아일랜드가 숨을 때까지 다시 줄어들지 않습니다.
- **실제 상태바에서 실시간으로.** 슬라이더를 끄는 대로 실제 상태바의 아일랜드가 따라옵니다. 최대 너비를 정하는 동안에는 샘플 항목에 긴 글이 들어 있어 알약이 그 너비까지 자라나는 모습을 볼 수 있고, 최소 너비를 정할 때는 짧은 글이 들어 있습니다.
- **두 너비는 서로를 넘지 못합니다.** 최소 너비는 최대 너비에서, 최대 너비는 최소 너비에서 멈춥니다. 최소 너비는 이제 420dp까지 정할 수 있습니다.
- **고침:** 최소 너비와, 높아진 알약의 더 큰 아이콘이 화면의 알약에 적용되지 않던 것을 고쳤습니다.
- *위치 초기화*는 이제 크기도 되돌립니다.
