# Dynamic Island 0.1.12-dev13 · Local test: six languages, English-first translations

Based on the local dev12 test build; no push or release is part of this delivery.

- Adds Japanese, Simplified Chinese and Russian alongside English, Korean and Turkish for settings, module-owned status-bar/card text and built-in stage labels. Each locale has all 388 translatable strings; technical identifiers and product names inherit the English source.
- English `res/values/strings.xml` is the source of truth. Language files and `locales_config.xml` are the translation entry points, including Android's per-app language list. Runtime catalogs and stage-label data are generated from the same strings, so adding a base language requires no Java translation table.
- Unknown locales or missing runtime values fall back to English. Existing user rule-label overrides retain priority over new translated defaults. Other apps' notification content is unchanged; built-in content-detection rules remain Korean and English.
- Adds a commented translation-template generator, completeness/duplicate/format-placeholder checks, CI/release validation and an English contributor guide in `docs/TRANSLATING.md`.
- Validation: Android settings and generated SystemUI catalogs agree across all six locales, including formatted values and percent signs; locale fallback and user rule overrides are tested. Japanese/Chinese/Russian settings pages are rendered headlessly. Full Android tests/build and translation-tool tests pass. Device feedback remains the next step.
- Retains dev12's reviewed notification options, battery/icons, colours, credits and the earlier tested media/shade fixes. APK uses the same local test signing key as previous local test builds.

## 한국어

로컬 dev12 테스트 빌드 기반이며 이번 전달에는 푸시·릴리스가 포함되지 않습니다.

- 영어·한국어·터키어에 일본어·중국어(간체)·러시아어를 추가합니다. 설정 화면·아일랜드 자체 문구·내장 단계 이름을 포함하며 각 언어의 번역 대상 문구 388개를 채웠습니다. 제품명·기술 식별자는 영어 원문을 공통으로 사용합니다.
- 영어 `res/values/strings.xml`을 기준으로 언어별 파일과 `locales_config.xml`에서 번역을 관리합니다. Android 앱별 언어 목록에도 등록하며, 상태바용 번역과 단계 이름도 같은 문자열에서 빌드 시 생성해 새 언어 추가에 Java 번역표 수정이 필요하지 않습니다.
- 지원하지 않는 언어나 누락된 문구는 영어로 표시합니다. 사용자 규칙의 기존 이름 수정은 새 기본 번역보다 우선합니다. 다른 앱의 알림 원문은 바꾸지 않으며 내장 내용 판별은 기존 한국어·영어 규칙을 유지합니다.
- 영어 원문 주석이 있는 번역 템플릿 생성, 누락·중복·자리표시자 검사, CI·릴리스 검증과 영어 번역 기여 안내를 추가합니다.
- 6개 언어의 Android 리소스와 상태바 번역 데이터, 숫자·퍼센트·영어 대체·사용자 규칙 우선순위를 검사합니다. 일본어·중국어·러시아어 설정 화면을 헤드리스로 렌더링했고 전체 Android 테스트·빌드와 번역 도구 검사가 통과했습니다. 실제 기기 확인은 다음 단계입니다.
- dev12의 알림 옵션·배터리·아이콘·색상·크레딧과 기존 미디어·알림창 수정은 유지합니다. APK는 이전 로컬 테스트 빌드와 같은 테스트 키로 서명합니다.
