# Dynamic Island 0.1.3 · Haptics fix and a new look for the project page

**English** · [한국어](#한국어)

A small release on top of 0.1.2.

## Fixes

- **Haptics:** the haptics switch now also covers the vibration Android itself starts when a card is pressed and held (the cards in the shade and the island). Before, that long-press vibration ignored the switch.

## Project page

- New title picture, social preview image and README header, with an English and a Korean version.
- Issue forms for bug reports (with a place for the diagnostics report) and for feature or rule requests.

## Install and notes

- Install the APK over 0.1.2; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If the haptics switch still has no effect, open **Tools → Diagnostics**, copy the report and send it with an issue; the `settings file` line shows whether System UI can read the settings.
