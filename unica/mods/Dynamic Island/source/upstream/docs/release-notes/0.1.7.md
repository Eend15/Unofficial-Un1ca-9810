# Dynamic Island 0.1.7 · One UI 7, flashlight brightness

**English** · [한국어](#한국어)

This release also carries everything of the test builds 0.1.6-dev2 to dev5.

## What's new

- **Flashlight brightness.** While the flashlight is on, the island shows it, and tapping it opens a card with a new flashlight icon and a big slider in the style of the iOS control centre. Drag it to change the brightness (5 levels on Galaxy phones, taken from the camera): the bar moves with your finger (the edge of the fill stays right under it, and small dots mark the levels) and, when you let go, glides to the nearest level as if pulled in by a magnet. Tap **Turn off** to switch it off. System UI's own "flashlight in use" notification is hidden while the card is there, so you do not get two. On a phone whose flashlight has only one level the plain "flashlight on" popup stays.
- **One UI 7 (Android 15).** The island now looks at what the phone's System UI actually has and attaches to that, instead of assuming One UI 8, so it can also run on One UI 7: the stock status-bar capsule is hidden, heads-up banners, calls and ongoing-activity cards are read, and the names that differ between versions are tried newest first. On One UI 7 the blurred shade cards and the shade music player of the island are off (One UI 7 has no such rows) and the stock shade stays; the screen-recording card is not there either. **Not tried on a phone yet.**
- **Phones without live blur.** Some phones cannot blur what is behind a card in real time. The island used to draw its cards see-through anyway, which made the text hard to read; it now asks the phone and, if there is no live blur (or *Reduce transparency* is on), draws solid cards.
- **Screen recording.** While the screen is being recorded and the island shows the recording card, the recorder's own "tap here to stop recording" notification is hidden from the notification panel (it follows the *hide original notifications* setting).
- **Music glow.** On a track change the glow behind the music card no longer flickers in brightness.
- **Diagnostics.** **Tools → Diagnostics** now also says which One UI version it runs on, which chip style and shade rows it found, whether blur is on and why not, and which hooks used an older name or did not attach.

## Install and notes

- Install over 0.1.6 or any 0.1.6 test build; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue. On One UI 7 please send the report whether it works or not.

## 한국어

0.1.6-dev2부터 dev5까지 테스트 빌드의 변경이 모두 들어 있습니다.

### 새로운 점

- **손전등 밝기 조절.** 손전등이 켜져 있는 동안 아일랜드에 표시되고, 누르면 아이폰 컨트롤 센터 스타일의 큰 슬라이더가 있는 카드(새 손전등 아이콘)가 열립니다. 슬라이더를 끌어 밝기(갤럭시는 5단계, 카메라에서 읽어 옵니다)를 바꿉니다. 막대는 손가락을 따라 움직이고(채워진 부분의 끝이 항상 손가락 바로 아래에 있고, 작은 점이 단계를 표시합니다), 손을 떼면 자석에 끌리듯 가장 가까운 단계로 미끄러져 갑니다. **끄기**를 눌러 끌 수 있습니다. 카드가 떠 있는 동안에는 시스템 UI의 "손전등 사용 중" 알림이 숨겨져서 두 개가 같이 뜨지 않습니다. 밝기 단계가 하나뿐인 폰에서는 기존의 "손전등 켜짐" 알림이 그대로 나옵니다.
- **One UI 7(안드로이드 15).** 이제 One UI 8이라고 가정하지 않고 폰의 시스템 UI에 실제로 있는 것을 보고 붙기 때문에 One UI 7에서도 돌 수 있습니다. 기본 상태바 캡슐을 숨기고, 헤드업 배너·통화·진행 중인 활동 카드를 읽고, 버전마다 이름이 다른 부분은 새 이름부터 시도합니다. One UI 7에서는 아일랜드의 블러 알림 카드와 알림창 음악 플레이어가 꺼지고(One UI 7에는 그런 알림 행이 없어서입니다) 기본 알림창이 그대로 남으며, 화면 녹화 카드도 나오지 않습니다. **아직 폰에서 확인하지 못했습니다.**
- **실시간 블러가 없는 폰.** 어떤 폰은 카드 뒤를 실시간으로 흐리게 만들지 못합니다. 그런데도 아일랜드가 카드를 비치게 그려서 글씨가 읽기 어려웠는데, 이제 폰에 물어보고 실시간 블러가 없으면(또는 **투명도 줄이기**가 켜져 있으면) 불투명한 카드를 그립니다.
- **화면 녹화.** 화면을 녹화하는 동안 아일랜드에 녹화 카드가 있으면, 녹화기가 띄우는 "녹화를 중지하려면 여기를 누르세요" 알림이 알림창에서 숨겨집니다(**원본 알림 숨기기** 설정을 따릅니다).
- **음악 글로우.** 곡이 바뀔 때 음악 카드 뒤 글로우의 밝기가 깜빡이던 것을 고쳤습니다.
- **진단.** **도구 → 진단**에 어느 One UI 버전인지, 어떤 칩 방식과 알림 행을 찾았는지, 블러가 켜졌는지(꺼졌다면 이유), 어떤 훅이 옛 이름으로 붙었거나 붙지 않았는지가 나옵니다.

### 설치와 참고

- 0.1.6 또는 0.1.6 테스트 빌드 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 검증했고 **실제 기기에서는 검증하지 못했습니다.** 동작하지 않으면 **도구 → 진단**의 리포트를 복사해 이슈와 함께 보내 주세요. One UI 7에서는 동작 여부와 상관없이 리포트를 보내 주세요.
