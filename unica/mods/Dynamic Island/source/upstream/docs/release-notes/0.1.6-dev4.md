# Dynamic Island 0.1.6-dev4 (pre-release)

**English** · [한국어](#한국어)

A test build on top of 0.1.6-dev3.

## What changed

- **Cards no longer turn see-through on phones without live blur.** Some phones (a Galaxy A30 with an unofficial One UI 7, for one) cannot blur what is behind a card in real time; they use a different kind of blur for their own windows. The island asked for the blur anyway, got none, and drew its cards 54 % see-through, so the text was hard to read on a busy wallpaper. The island now asks the phone whether it has live blur (and whether *Reduce transparency* is on) and, if not, draws solid cards instead.
- **Diagnostics tell why.** **Tools → Diagnostics** has a `blur` line: `real-time` or `off: ...` with the reason.

## Install and notes

- Install over any 0.1.6 build; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

0.1.6-dev3 위에 얹은 테스트 빌드입니다.

### 바뀐 점

- **실시간 블러가 없는 폰에서 카드가 비치지 않게.** 어떤 폰(예: 비공식 One UI 7을 올린 갤럭시 A30)은 카드 뒤를 실시간으로 흐리게 만들지 못하고, 자기 창에는 다른 방식의 블러를 씁니다. 아일랜드는 블러를 요청해도 아무 효과가 없는데 카드를 54% 투명하게 그려서, 복잡한 배경화면 위에서 글씨가 읽기 어려웠습니다. 이제 폰에 실시간 블러가 있는지(그리고 **투명도 줄이기**가 켜져 있는지) 물어보고, 없으면 카드를 불투명하게 그립니다.
- **진단에 이유가 나옵니다.** **도구 → 진단**에 `blur` 줄이 있어 `real-time` 또는 `off: ...`와 이유를 보여 줍니다.

### 설치와 참고

- 0.1.6 계열 어느 빌드 위에든 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 검증했습니다. 동작하지 않으면 **도구 → 진단**의 리포트를 복사해 이슈와 함께 보내 주세요.
