# Dynamic Island 0.1.13

**Stable release** · Changes since **0.1.12**, including **0.1.13-dev1**, **dev2** and the subsequent tested fixes · **English** / [한국어](#한국어)

This release adds music-reactive glow, clearer settings, optional charging and headset cards, a voice-recording waveform, and more consistent card layouts. It also fixes the live-notification long-press crash reported in #16.

## Music and glow

- The main pill and additional bubble share the active music session's album colours and sound response, including when the music card itself is hidden. Glow is **on by default for music sessions only**; saved choices are preserved.
- Brightness and dynamic strength have separate **0–100%** controls, defaulting to **45%** and **50%**. Use theme colours, an individual preset/HSV/HEX colour, or album matching.
- Pausing makes the glow faint and settles its motion. Ending a music session fades its last colours out over **1.2 seconds**. A new session can smoothly interrupt the fade.
- Improve media foreground detection so opening the player does not briefly show a duplicate island ([#18](https://github.com/sampple-korea/dynamicisland/issues/18)). Voice-recording sessions remain excluded from music selection.

## Cards and recording

- **Circular battery gauges:** Keep the percentage in one place, show charging metrics and optional statistics separately, and remove duplicate progress information. Device cards separate the device name, connection status and battery gauge.
- **More useful compact content:** Battery percentage, charging power, device identity and toggle state use their own spaces. Layouts respect the camera cutout and available width.
- **Consistent card corners:** Expanded cards use the original shared **28dp** radius. **Appearance → Card corners** optionally enables a **0–48dp** radius with a live preview; switching it off restores 28dp. Compact pills keep their original shape.
- Timers preserve their full time readout, size to the text and move controls below it when needed. Individual action buttons retain their original icons and colours.
- **Experimental voice waveform** ([#12](https://github.com/sampple-korea/dynamicisland/issues/12)): Enable **Advanced & troubleshooting → Concurrent microphone waveform (experimental)** for Samsung Voice Recorder. It shows actual input levels in compact and expanded views without adding the recorder app to LSPosed scope. It is **off by default**; device audio policies can reject concurrent input or affect recording, so turn it off if needed. Low-performance mode disables it. No audio is stored or transmitted.
- The recording waveform keeps roughly three seconds of history and moves on display frames between microphone reads. Its timing uses one clock domain, so deep sleep no longer breaks interpolation. Pause/stop, hidden views, stale input and blocked input stop continuous work.
- Preserve screen-recording time across notification updates and rolling timestamps, anchoring it to the recording session ([#17](https://github.com/sampple-korea/dynamicisland/issues/17)).

[View 36 current card examples](https://github.com/sampple-korea/dynamicisland/blob/v0.1.13/docs/cards-overview-0.1.13.png) · Illustrative content; optional features are included. Device fonts, native backdrop blur and app-provided layouts can differ.

## Settings and device options

- Reorganised settings pages, clearer notification modes, searchable app selection with Save/Cancel, separate rule tools and **Galaxy-style switches**. Position, size and camera calibration reset independently; navigation preserves scroll position.
- **Optional live charging card and statistics:** Current, estimated power, temperature and charge level, plus measured screen-on/off time and estimated net charge changes. Both are off by default. Collection follows the switches; screen-off polling pauses. Power and charge splits are estimates, and unknown readings stay unknown.
- **Optional wired/USB headset alerts**, off by default, announce real connection changes without announcing an already-connected device when enabled.
- **Samsung battery charging effect:** Hidden by default, with an opt-in switch under **Notifications → System events** ([#15](https://github.com/sampple-korea/dynamicisland/issues/15)). Ordinary battery information, privacy indicators, charging sounds and warnings remain available. The corrected effect suppression was confirmed on the maintainer's device.
- **Portrait full-screen visibility**, off by default, can keep active content visible when an app hides the status bar; lock-screen/AOD and landscape rules still apply ([#14](https://github.com/sampple-korea/dynamicisland/issues/14)).
- **Low-performance mode**, off by default, uses simpler rendering, stops audio analysis and limits continuous motion to 30fps while touch/transitions can use up to 60fps. Individual preferences are retained.
- **Outline:** Automatic, Always and None; automatic sampling stops for hidden windows and rejects stale results. **Camera text clearance:** Additional 0–16dp, default 0dp.
- **Experimental notification recovery**, off by default, selects the alternate One UI 8 notification handling only when enabled. App exclusions and notification/verification-code settings continue to apply.

## System UI fixes and validation

- **Live-notification long-press crash** ([#16](https://github.com/sampple-korea/dynamicisland/issues/16)): Samsung's action-button hit test dereferenced an expanded child removed by our replacement card. During that synchronous check, it now searches the displayed card; the reference is restored afterward. The normal notification menu, snooze and bubble checks are preserved. This was identified from the supplied One UI 8.5 logs, checked against SystemUI code and reproduced in a focused test; confirmation on the reporting phone is still welcome.
- **System typography** ([#20](https://github.com/sampple-korea/dynamicisland/issues/20)): Follow Samsung's system family and FlipFont choices, including cached typeface updates, and remeasure visible content after font changes.
- **102 default Android tests**, translation-tool tests and the APK build pass. Visual-only captures remain opt-in. The current preview covers all nine card body implementations through 36 examples.
- **515/515 strings** in each supported language: English, Korean, Japanese, Simplified Chinese, Russian and Turkish. All six READMEs describe the new release; English remains the translation source.
- Headless validation does not replace testing microphone policy, sensor readings or GPU effects on each phone. One UI 7 and Nothing OS support remains unconfirmed on a real device.

## Installation

The official APK uses the project's existing release signing key and can update previous official releases. **A separately signed local test APK must be uninstalled before installing the official build; save any settings you need first.** Restart SystemUI or reboot after installation. Use **Advanced & troubleshooting → Diagnostics** when reporting a problem.

## 한국어

**정식 0.1.12 이후 변경사항**을 모은 **0.1.13 정식판**입니다. **0.1.13-dev1·dev2**와 이후 테스트한 수정사항을 포함합니다.

### 음악과 글로우

- 메인 알약과 추가 버블이 같은 음악 세션의 앨범 색과 소리 반응을 공유합니다. 음악 카드 자체가 숨겨져 있어도 적용하며 **기본 켜짐·음악 세션 전용**입니다. 기존에 저장한 선택은 유지합니다.
- 밝기와 다이내믹 효과 강도를 **0–100%**로 각각 조절합니다. 기본값은 **45%·50%**입니다. 테마색, 개별 프리셋·HSV·HEX 색상과 앨범 연동을 지원합니다.
- 일시정지하면 빛이 약해지고 움직임도 잦아듭니다. 세션이 끝나면 마지막 앨범 색을 유지하며 **1.2초 동안 사라지고**, 새 세션이 생기면 부드럽게 이어집니다.
- 플레이어를 열 때 아일랜드가 잠깐 중복 표시되는 문제를 개선했습니다([#18](https://github.com/sampple-korea/dynamicisland/issues/18)). 음성 녹음 세션은 음악에서 계속 제외합니다.

### 카드와 녹음

- **원형 배터리 게이지:** 퍼센트를 중복하지 않고 충전 정보와 통계를 구분합니다. 기기 카드도 기기 이름·연결 상태·배터리 게이지를 나눠 표시합니다.
- **축소 정보 개선:** 배터리 퍼센트·충전 전력·기기 이름·설정 상태를 각각의 공간에 표시하고, 카메라 구멍과 화면 너비를 고려합니다.
- **카드 곡률:** 펼친 카드는 기존 공통 **28dp**를 사용합니다. **모양 → 카드 모서리**에서 직접 조절을 켜면 **0–48dp**로 미리 보며 변경할 수 있고, 끄면 28dp로 돌아갑니다. 축소 알약 모양은 유지합니다.
- 타이머는 시간 전체를 표시하고 글자 크기와 여유 공간에 맞춰 버튼을 아래로 배치합니다. 기존 개별 버튼의 아이콘과 원래 색상을 유지합니다.
- **실험적 음성 녹음 파형**([#12](https://github.com/sampple-korea/dynamicisland/issues/12)): **고급 및 문제 해결 → 동시 마이크 파형 (실험적)**에서 켭니다. 삼성 음성 녹음의 실제 입력 음량을 축소·확장 화면에 표시하며 녹음기를 LSPosed 스코프에 추가하지 않아도 됩니다. **기본 꺼짐**입니다. 기기의 오디오 정책에 따라 동시 입력이 차단되거나 녹음에 영향이 있을 수 있으므로 문제가 생기면 끄세요. 저사양 모드에서는 사용하지 않으며 오디오를 저장하거나 전송하지 않습니다.
- 녹음 파형은 약 3초의 이력을 유지하며 입력 사이에도 화면 프레임에 맞춰 움직입니다. 입력과 표시의 시간 기준을 통일해 깊은 절전 후 보간이 끊기는 문제도 수정했습니다. 일시정지·종료, 숨김, 입력 중단·차단 시 연속 작업을 멈춥니다.
- 화면 녹화 시간을 세션 시작에 고정해 알림 갱신과 시스템 타임스탬프 변경으로 초기화되는 문제를 수정했습니다([#17](https://github.com/sampple-korea/dynamicisland/issues/17)).

[현재 카드 36가지 예시 보기](https://github.com/sampple-korea/dynamicisland/blob/v0.1.13/docs/cards-overview-0.1.13.png) · 내용은 예시이며 선택 기능도 포함합니다. 실제 기기의 폰트·배경 블러·앱 자체 레이아웃은 다를 수 있습니다.

### 설정과 기기 옵션

- 설정 페이지와 알림 표시 방식을 정리하고, 저장·취소가 있는 앱 검색과 규칙 도구, **갤럭시 스타일 스위치**를 적용했습니다. 위치·크기·카메라 보정은 따로 초기화하고 스크롤 위치를 보존합니다.
- **선택형 충전 상세 카드·충전 통계:** 전류·추정 전력·온도·잔량과 화면 켜짐/꺼짐 시간·추정 순충전 변화를 표시합니다. 둘 다 기본 꺼짐이며, 옵션에 맞춰 수집하고 화면이 꺼지면 폴링을 멈춥니다. 전력·상태별 충전량은 추정치이며 읽지 못한 값은 알 수 없음으로 둡니다.
- **유선·USB 이어폰 알림:** 기본 꺼짐이며 실제 연결 변화를 알려줍니다. 옵션을 켰을 때 이미 연결된 기기를 새 연결로 알리지 않습니다.
- **삼성 배터리 아이콘 충전 효과:** 기본 숨김이며 **알림 → 시스템 이벤트**에서 다시 켤 수 있습니다([#15](https://github.com/sampple-korea/dynamicisland/issues/15)). 일반 배터리 정보·개인정보 표시·충전 소리·경고는 유지합니다. 수정한 효과 차단은 관리자의 실제 기기에서 확인했습니다.
- **세로 전체 화면 표시:** 기본 꺼짐이며 앱이 상태바를 숨겨도 사용 중인 콘텐츠를 표시할 수 있습니다. 잠금 화면·AOD·가로 화면 규칙은 유지합니다([#14](https://github.com/sampple-korea/dynamicisland/issues/14)).
- **저사양 모드:** 기본 꺼짐입니다. 렌더링을 간소화하고 오디오 분석을 멈추며, 연속 모션은 30fps, 터치·전환은 최대 60fps로 제한합니다. 개별 설정은 보존합니다.
- **테두리:** 자동·항상·없음. 숨겨진 창에서는 배경 샘플링을 멈추고 오래된 결과를 무시합니다. **카메라 옆 추가 여백:** 0–16dp, 기본 0dp입니다.
- **실험적 알림 복구:** 기본 꺼짐이며 켰을 때만 대체 One UI 8 알림 처리 방식을 사용합니다. 앱 제외·알림 표시·인증번호 설정은 계속 적용합니다.

### 시스템 UI 수정과 검증

- **라이브 알림 길게 누르기 크래시**([#16](https://github.com/sampple-korea/dynamicisland/issues/16)): 삼성 버튼 판별 코드가 교체 카드에서 비워 둔 펼침 뷰를 읽던 문제였습니다. 해당 판별 중에만 표시 중인 카드를 참조하고 이후 되돌립니다. 일반 메뉴와 다시 알림·버블 판정도 유지합니다. 제공된 One UI 8.5 로그와 SystemUI 코드를 분석하고 재현 테스트로 확인했으며, 신고 기기의 추가 확인을 환영합니다.
- **시스템 폰트**([#20](https://github.com/sampple-korea/dynamicisland/issues/20)): 삼성 시스템 글꼴·FlipFont 선택과 캐시된 글꼴 갱신을 따르고, 변경 후 표시 중인 콘텐츠를 다시 측정합니다.
- **기본 안드로이드 테스트 102개**, 번역 도구 테스트와 APK 빌드를 통과했습니다. 이미지 생성은 별도 선택이며 현재 미리보기는 카드 렌더러 9종을 36가지 예시로 보여줍니다.
- 영어·한국어·일본어·중국어 간체·러시아어·터키어 **각 515/515개 문자열**을 지원하고 README 6개도 업데이트했습니다. 영어를 번역 원문으로 유지합니다.
- 자동 검증은 각 기기의 마이크 정책·센서·GPU 효과 검증을 대신하지 않습니다. One UI 7·Nothing OS는 실제 기기 확인이 아직 없습니다.

### 설치

기존 공식 서명으로 배포하므로 이전 공식판에서 업데이트할 수 있습니다. **별도 서명한 로컬 테스트 APK가 설치되어 있다면 필요한 설정을 보존한 뒤 삭제하고 공식판을 설치해야 합니다.** 설치 후 SystemUI를 재시작하거나 재부팅하세요. 문제 제보 시 **고급 및 문제 해결 → 진단**을 첨부해 주세요.
