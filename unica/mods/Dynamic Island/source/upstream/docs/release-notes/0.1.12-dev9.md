# Dynamic Island 0.1.12-dev9 · Turkish language support

**English** · [한국어](#한국어)

A pre-release based on 0.1.12-dev8, adding Turkish language support requested in #9.

## Changes

- All 282 settings strings are available in Turkish, selected automatically when the phone's language is Turkish.
- Module-generated island text is translated: system events, charging and Bluetooth, privacy indicators, flashlight, recording and screen sharing, reply and verification-code buttons, call controls and position previews. Text supplied by other apps is left unchanged.
- All 27 built-in status labels across nine rule types have Turkish translations. Existing user-defined stage names continue to take priority, including older English/Korean-only customizations.
- Turkish notification action labels are recognized for stop/cancel/end, speaker and mute/unmute, including dotted and dotless I. Pausing actions remain non-destructive.
- Built-in notification-content detection remains based on the existing Korean and English rules; this release does not add Turkish delivery/navigation text-detection rules.

## Validation and installation

- Added regression tests for locale selection, Turkish Android resources and formatting, built-in stage-label coverage, existing-language behavior, custom-label compatibility and action classification.
- Local Android release compilation and APK packaging passed. A separate 27-test core-logic run passed. The full Robolectric suite could not run on the local Linux ARM64 host because its native runtime is unsupported there; the release workflow runs the full suite on Linux x86_64 before signing and publishing.
- **Not yet confirmed on a real device in Turkish.** Feedback on wording and layout is welcome.
- The APK uses the project's existing release signing key. Update and restart System UI after installation; set the phone's language to Turkish to use the translations.

## 한국어

0.1.12-dev8 기반의 프리릴리스로, #9에서 요청한 터키어 지원을 추가합니다.

### 변경

- 설정 문자열 282개를 모두 터키어로 번역했습니다. 휴대전화 언어가 터키어이면 자동 적용됩니다.
- 시스템 이벤트, 충전·블루투스, 개인정보 표시, 손전등, 녹화·화면 공유, 답장·인증번호 버튼, 통화 조작과 위치 미리보기 등 모듈이 생성하는 아일랜드 문구를 번역했습니다. 다른 앱이 보내는 원문은 변경하지 않습니다.
- 내장 규칙 9종의 단계 이름 27개를 터키어로 제공합니다. 기존 영어·한국어 형식으로 저장한 사용자 지정 단계 이름도 새 번역보다 우선하도록 호환성을 유지했습니다.
- 터키어 알림 버튼의 중지·취소·종료, 스피커, 음소거·해제 표현을 인식합니다. 점 있는 I와 점 없는 I를 처리하고, 일시정지는 파괴적 동작으로 분류하지 않습니다.
- 내장 알림 내용 감지는 기존 한국어·영어 규칙을 그대로 사용합니다. 이번 버전에 터키어 배달·길안내 알림 문구 감지 규칙을 추가한 것은 아닙니다.

### 검증과 설치

- 언어 선택, 터키어 Android 리소스·서식, 내장 단계 번역 누락, 기존 언어 동작, 사용자 라벨 호환성, 버튼 분류에 대한 회귀 테스트를 추가했습니다.
- 로컬 Android 릴리스 컴파일·APK 생성과 별도 핵심 로직 테스트 27개가 통과했습니다. 로컬 Linux ARM64는 Robolectric 네이티브 런타임이 지원되지 않아 전체 테스트를 실행할 수 없었으며, 릴리스 워크플로가 Linux x86_64에서 전체 테스트를 수행한 뒤 서명·배포합니다.
- **터키어 설정의 실제 기기에서는 아직 확인하지 못했습니다.** 번역이나 화면 배치에 대한 피드백을 부탁드립니다.
- APK는 프로젝트의 기존 배포 키로 서명합니다. 업데이트 후 시스템 UI를 재시작하고, 번역을 사용하려면 휴대전화 언어를 터키어로 설정하세요.
