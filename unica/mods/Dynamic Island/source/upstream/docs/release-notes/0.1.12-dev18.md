# Dynamic Island 0.1.12-dev18 · Material-style content transitions

Local test APK only; no push or release.

- Adds a foreground-only material-style transition using Android RenderEffect Gaussian blur, up to 10dp. Apple Material APIs are not available on Android. Text, icons and controls soften as they leave, and resolve into focus as they appear. The black pill, outline and card backdrop are outside this filter.
- Uses per-content GPU RenderNodes for Canvas cards/compact content and cached View RenderEffects for custom notification layouts. There are no per-frame CPU bitmap blurs. Gaussian effects are cached in 20 levels; steady content draws directly and releases its recorded blur buffer. Software captures retain their content and fades without GPU blur.
- Replaces separate compact/expanded delays with a shared 220ms crossfade. Both UI weights sum to one, reversing preserves the current state, compact geometry starts regrowing immediately, and the main expanded body participates as a whole rather than waiting for a second delayed row fade. Additional cards retain their stagger. Reopening mid-collapse retargets the same card rather than duplicating it.
- Preserves the opaque compact body and dev16's outer-rim-only outline fix. Remote notification foreground is clipped to its current card bounds and its effect is cleared when hidden or removed.
- The old timing fails native Canvas content-pixel checks during opening at 60/120Hz and during a rapid reversal. The revised tests count coloured UI pixels rather than borders, checking each rendered frame for an empty transition. Custom notification layouts follow the current card scale while opening. Additional checks cover hardware display-list recording, separate card nodes, effect reuse/cleanup, bounded blur curves and reversal continuity.
- Native Canvas software films cannot show the final GPU Gaussian appearance. Verify the effect on the affected Samsung device after restarting SystemUI or rebooting.

## 한국어

로컬 테스트 APK이며 푸시·릴리스는 하지 않습니다.

- 글자·아이콘·버튼에만 머티리얼 스타일 블러를 적용합니다. 나타날 때 흐림이 걷히고, 사라질 때 흐려집니다. 안드로이드 RenderEffect의 최대 10dp 가우시안 블러를 사용하며, 애플 전용 API를 사용하는 것은 아닙니다. 검은 본체·테두리·카드 배경에는 이 효과를 걸지 않습니다.
- 캔버스 내용은 각각의 GPU RenderNode로, 앱 제공 알림 레이아웃은 View 효과로 처리합니다. 매 프레임 CPU 비트맵 블러를 만들지 않고, 효과를 20단계로 캐시합니다. 전환이 끝나면 선명하게 직접 그리고 기록 버퍼를 해제합니다.
- 두 UI의 독립적인 표시 지연을 없애고 220ms 교차 전환으로 맞춥니다. 양쪽 표시 비중의 합은 항상 1이며, 중간에 방향을 바꿔도 현재 상태에서 이어집니다. 작은 본체도 즉시 크기를 복원하고, 첫 카드의 내부는 별도의 행 지연 없이 함께 전환됩니다. 추가 카드의 순차 등장은 유지합니다. 접는 도중 다시 펼치면 이동 중인 카드를 이어서 사용해 중복 카드가 생기지 않습니다.
- 불투명한 작은 본체와 테두리 내부 채움 제거를 유지합니다. 앱 제공 알림 내용도 펼침 크기를 따라가며 카드 경계 안으로 제한하고, 숨기거나 제거하면 효과를 해제합니다.
- 기존 코드에서 실제 내용 픽셀이 사라졌던 60·120Hz 펼침과 도중 반전 검사를 포함합니다. 테두리가 아닌 색 있는 UI 픽셀을 매 프레임 검사합니다. GPU 기록 경로·카드별 분리·효과 캐시와 해제·블러 진행률·반전 연속성도 검사합니다.
- 소프트웨어 캔버스 검사는 최종 GPU 블러의 모양을 보여주지 못하므로 실제 기기 확인이 필요합니다. 업데이트 후 SystemUI 재시작 또는 재부팅으로 적용합니다.
