# Dynamic Island 0.1.5 · A much better rule editor

**English** · [한국어](#한국어)

Rules are how the island turns plain notifications (deliveries, rides, a running service, a connected device) into cards. This release makes writing your own rules easy, and gives every rule more to adjust.

## What's new

- **A new-rule wizard.** Tap **New rule** in the rule list and answer five short steps on one page: the name, what kind of rule it is, which notifications it is about, the stages, and how the card looks. At the bottom you can type a notification text and see what the rule would read from it before you make the rule. The button turns on when the rule has what it needs.
- **Two kinds of rule.** Pick *something that goes through stages* (an order, a ride, a parcel) or *a state* (a service is running, a device is connected). A state has one stage, no progress bar, and stays as long as its notification does.
- **More to adjust on every rule.** Open a rule and you will find a **Card** section: its name, the card colour, whether the card has a progress bar, whether the original notification is hidden from the notification panel while the card is on the island, how long the card stays, how long it stays after the last stage, and how long it stays quiet after it left. This also works on the rules that come with the module; your settings go on top and **Reset my changes** brings the original back.
- **Words as well as apps.** A rule can now also read notifications by words in their text, from any app.
- **Try a pattern while you write it.** When you edit a stage, type a sample text and the editor tells you at once whether the pattern is valid, whether it finds something in the text, and what a percentage group would read.

## Install and notes

- Install the APK over 0.1.4; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report and send it with an issue.

## 한국어

규칙은 아일랜드가 평범한 알림(배달, 택시, 실행 중인 서비스, 기기 연결 같은 것)을 카드로 바꾸는 방법입니다. 이번 버전은 나만의 규칙을 쉽게 만들 수 있게 하고, 모든 규칙에서 조절할 수 있는 것을 늘렸습니다.

### 새로운 점

- **새 규칙 마법사.** 규칙 목록에서 **새 규칙**을 누르면 한 화면에서 짧은 다섯 단계에 답하면 됩니다. 이름, 어떤 규칙인지, 어떤 알림에 대한 것인지, 단계, 카드의 모양입니다. 맨 아래에서는 규칙을 만들기 전에 알림 글을 넣어 보고 규칙이 거기서 무엇을 읽는지 미리 볼 수 있습니다. 필요한 것이 다 갖춰지면 만들기 버튼이 켜집니다.
- **두 가지 규칙.** *단계가 이어지는 일*(주문, 택시, 택배)과 *하나의 상태*(서비스가 실행 중, 기기가 연결됨) 중에서 고릅니다. 상태 규칙은 단계가 하나이고 진행 막대가 없으며, 알림이 있는 동안 카드도 남습니다.
- **모든 규칙에서 더 많이 조절.** 규칙을 열면 **카드** 항목이 있습니다. 규칙의 이름, 카드 색, 진행 막대를 보일지, 카드가 아일랜드에 떠 있는 동안 알림창에서 원본 알림을 숨길지, 카드가 머무는 시간, 마지막 단계 뒤에 머무는 시간, 사라진 뒤 조용히 있는 시간을 정할 수 있습니다. 모듈에 들어 있는 규칙에서도 되고, 내 설정이 위에 얹히며 **내 변경 되돌리기**로 원래대로 돌아갑니다.
- **앱뿐 아니라 단어로도.** 이제 규칙이 알림 글의 단어로도 알림을 읽을 수 있습니다. 어느 앱의 알림이든 됩니다.
- **쓰면서 패턴 시험.** 단계를 편집할 때 시험해 볼 글을 쓰면, 패턴이 올바른지, 글에서 무언가를 찾는지, 퍼센트 그룹이 무엇을 읽는지 바로 알려 줍니다.
