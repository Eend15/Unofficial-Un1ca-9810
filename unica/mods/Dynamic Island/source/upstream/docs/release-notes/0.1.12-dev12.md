# Dynamic Island 0.1.12-dev12 · Local test: notification options and colours

Local test build on the current main branch, retaining the tested shade motion, media/recording fixes, album gradients, Turkish support and credits. No push or release is part of this test delivery. Versioning follows upstream rather than the third-party ZIP.

- New opt-in switches: show notifications from the foreground app; automatically open newly arriving activity/progress/recording cards for four seconds. Both default off. Auto-open skips the existing backlog, remembers updates without reopening, expires delayed candidates, and waits while another card or reply is open.
- New opt-in experimental notification recovery switch, default off: broader indeterminate-progress detection, promoted-progress fallback, Now Bar activities, alternate chip hooks and broader screen-recorder package detection. Existing filters for calls/media remain, and notification source keys prevent duplicate fallback cards.
- Incoming messages may replace an open card, while replies and the pulled shade are protected. Text-bearing group summaries are accepted when no eligible child in the same Android user/group represents them.
- Heads-up removal is limited to the matching notification posting actually displayed by the island under its existing enabled options. Manager capture is expanded; bounded retries stop when ownership is lost. Unreadable state is reported as unknown rather than successful removal.
- Up to four progress-card packages are supported. Clock digits use fixed cells and scale down when needed. Source updates and original-row hiding retain their existing behaviour.
- Duplicate shade cards restore stock content first, including during a rebind, and reconcile when the overlay opens/closes or the shade moves.
- Colours page: six presets, card preview, cancellable HSV/hex editor, input validation and restore-original-colours action. Custom colours default off; ordinary fills change only when enabled. Media, artwork, destructive controls and app-defined action colours retain priority. English, Korean and Turkish strings are included.
- Charging/low-battery pictograms use the supplied battery vectors, with the existing Lottie fallback if module resources cannot be read. Other Lottie pictograms remain. Battery icons are hidden by default via a new switch; title, percentage and progress remain. Toggling the switch updates a visible battery event.
- Event-card pictograms default to 40dp after user review of the size comparison; a new Small event card icons switch restores 22dp. Hidden battery icons reserve no empty icon column. No unused font or generic resource-loader reflection is imported.
- Adds bounded chip/progress/recorder/icon diagnostics; imports the reviewed clock/pill tests and adds regression checks for opt-in recovery, deduplication, reply protection, auto-open history, shade-row restoration and colour editing.

## 한국어

최신 main을 기준으로 준비한 로컬 테스트 빌드입니다. 검증된 알림창 애니메이션·미디어/녹음 수정·앨범 그라데이션·터키어·크레딧을 유지합니다. 이번 전달에는 푸시·릴리스가 포함되지 않으며, 버전 체계도 외부 ZIP 대신 업스트림을 따릅니다.

- 사용 중인 앱의 알림 표시와 새 활동·진행 상황·녹화 카드의 4초 자동 펼침 옵션을 추가합니다. 둘 다 기본 꺼짐입니다. 기존 알림을 한꺼번에 열거나 갱신마다 재차 열지 않으며, 기다리는 카드는 만료시키고 다른 카드·답장 입력을 방해하지 않습니다.
- 알림 호환성 복구 옵션을 실험 기능으로 묶었습니다. 기본 꺼짐이며 무한 진행 막대, 승격 진행 알림 대체, Now Bar 활동, 대체 칩 훅, 화면 녹화 앱 추가 감지를 포함합니다. 통화·미디어 필터는 유지하고 같은 알림의 중복 카드도 걸러냅니다.
- 카드가 열려 있어도 새 메시지를 표시하되 답장 입력과 펼쳐진 알림창은 보호합니다. 내용이 있는 그룹 요약 알림은 같은 사용자·그룹에 대신 표시할 자식 알림이 없을 때만 사용합니다.
- 기본 팝업 제거는 기존 옵션에 따라 아일랜드가 실제로 표시한 동일 알림 게시 건에만 적용합니다. 관리자 참조 수집을 보완하고 재시도를 제한하며, 표시 소유권이 없어지면 중단합니다. 확인 불가능한 상태를 제거 성공으로 판정하지 않습니다.
- 진행 카드의 앱 수를 최대 4개로 늘리고, 시계 숫자는 고정 폭과 공간에 맞춘 축소를 사용합니다.
- 알림창 중복 카드는 먼저 원래 행을 복원하며 재바인딩 중에도 복원 상태를 지킵니다. 아일랜드 카드가 열리거나 닫힐 때와 알림창 전환에 맞춰 다시 맞춥니다.
- 색상 설정에 프리셋 6개, 카드 미리보기, 취소 가능한 HSV·HEX 조정, 입력 검증과 원래 색상 복원을 추가합니다. 기본 꺼짐이며 켰을 때만 일반 채우기 색에 적용합니다. 음악·이미지·위험 버튼·앱이 지정한 동작 색상은 우선합니다. 한국어·영어·터키어를 지원합니다.
- 충전·배터리 부족 아이콘만 제공받은 배터리 벡터로 바꾸며 리소스를 읽지 못하면 기존 Lottie로 대체합니다. 다른 Lottie 아이콘은 유지합니다. 배터리 아이콘 숨김은 기본 켜짐이며 제목·퍼센트·진행 막대는 남깁니다. 표시 중에도 설정 전환을 반영합니다.
- 사용자가 크기 비교 시안을 확인한 뒤 이벤트 카드 아이콘을 기본 40dp로 확대하며, 작은 이벤트 카드 아이콘 옵션을 켜면 기존 22dp로 돌아갑니다. 배터리 아이콘을 숨기면 빈 아이콘 영역도 남기지 않습니다. 사용하지 않는 폰트나 범용 리소스 로더는 가져오지 않습니다.
- 칩·진행 카드·녹화 미분류·배터리 아이콘 진단을 보강하고, 숫자·알약 테스트와 옵션·중복·답장 보호·자동 펼침·행 복원·색상 조정 회귀 검사를 추가합니다.
