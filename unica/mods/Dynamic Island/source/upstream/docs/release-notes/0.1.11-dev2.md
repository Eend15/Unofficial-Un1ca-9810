# Dynamic Island 0.1.11-dev2 · Test build: one pill when closing

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.10.

## What's new

- **One pill when the cards close.** While the cards fold back, the pill itself is kept out of sight, so you no longer see a pill at the top and a card moving into it. The card is the pill on its way back; when it arrives the pill (with its icon and text) takes over, and then the small circle next to it splits out.

## Install and notes

- Install over 0.1.10; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment, **not on a real device**. If the closing still looks wrong, send a screen recording together with the report of **Tools → Diagnostics**.

## 한국어

0.1.10 위에 얹은 테스트용 프리릴리스입니다.

### 새로운 점

- **카드가 닫힐 때 알약이 하나로 보입니다.** 카드가 접혀 들어가는 동안에는 원래 알약을 보이지 않게 해서, 위쪽의 알약과 그 안으로 들어가는 카드가 동시에 보이지 않습니다. 카드가 알약으로 돌아가는 모습 자체가 하나의 알약이고, 카드가 도착하면 알약(아이콘과 글자 포함)이 이어받은 뒤 알약 옆의 작은 원이 갈라져 나옵니다.
