# Dynamic Island 0.1.6-dev3 (pre-release)

**English** · [한국어](#한국어)

A test build on top of 0.1.6: the first one that is meant to also run on **One UI 7** (Android 15).

## What changed

- **One UI 7 support (not tried on a phone yet).** The module now looks at what the phone's System UI actually has and attaches to that, instead of assuming One UI 8. On One UI 7 it hides the stock status-bar capsule in the One UI 7 way, takes over heads-up banners, reads calls from the system call controller and shows the ongoing-activity cards. The blurred shade cards and the shade music player of the island are off on One UI 7, because One UI 7 does not have the rows they are built on; the stock shade stays.
- **Names are tried newest first.** Where a System UI part is called differently between versions, the module tries the newer name first and then the older one. **Tools → Diagnostics** now says which One UI version it runs on, which chip style it found, and which hooks used an older name or did not attach.
- **Screen recording** (from dev2): the recorder's own notification is hidden from the notification panel while the island shows the recording card.
- **Music glow** (from dev2): no brightness flicker when the track changes.

## Install and notes

- Install over 0.1.6 or 0.1.6-dev2; it is signed with the same key. Restart System UI afterwards.
- **Not verified on a real device**, on One UI 7 or any other. On One UI 7 please open **Tools → Diagnostics**, copy the report and send it with an issue, whether it works or not: it lists which hooks attached.

## 한국어

0.1.6 위에 얹은 테스트 빌드이고, **One UI 7**(안드로이드 15)에서도 돌도록 만든 첫 빌드입니다.

### 바뀐 점

- **One UI 7 지원(아직 폰에서 확인하지 못했습니다).** 이제 One UI 8이라고 가정하지 않고, 폰의 시스템 UI에 실제로 있는 것을 보고 거기에 붙습니다. One UI 7에서는 기본 상태바 캡슐을 One UI 7 방식으로 숨기고, 헤드업 배너를 가져오고, 통화를 시스템 통화 컨트롤러에서 읽고, 진행 중인 활동 카드를 보여 줍니다. 아일랜드의 블러 알림 카드와 알림창 음악 플레이어는 One UI 7에서는 꺼집니다. 그것들이 얹히는 알림 행이 One UI 7에는 없어서이고, 기본 알림창이 그대로 남습니다.
- **새 이름부터 시도.** 시스템 UI의 같은 부분이 버전마다 다른 이름이면, 새 이름을 먼저 시도하고 없으면 옛 이름을 시도합니다. **도구 → 진단**에 어느 One UI 버전인지, 어떤 칩 방식인지, 어떤 훅이 옛 이름으로 붙었거나 붙지 않았는지 나옵니다.
- **화면 녹화**(dev2부터): 아일랜드에 녹화 카드가 있는 동안 녹화기의 알림이 알림창에서 숨겨집니다.
- **음악 글로우**(dev2부터): 곡이 바뀔 때 밝기가 깜빡이지 않습니다.

### 설치와 참고

- 0.1.6 또는 0.1.6-dev2 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- One UI 7을 포함해 **실제 기기에서는 검증하지 못했습니다.** One UI 7에서는 동작 여부와 상관없이 **도구 → 진단**의 리포트를 복사해 이슈와 함께 보내 주세요. 어떤 훅이 붙었는지 적혀 있습니다.
