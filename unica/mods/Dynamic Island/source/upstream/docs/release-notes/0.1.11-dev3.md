# Dynamic Island 0.1.11-dev3 · Test build: closing animation

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.10.

## What's new

- **One pill when the cards close.** While the cards fold back the pill itself is kept out of sight, so there is no pill at the top plus a card moving into it. The card is the pill on its way back; when it arrives the pill (with its icon and text) takes over and the small circle next to it splits out.
- **No grey flash when going in.** A card now turns from the grey glass into the pill's black step by step along its fold, instead of in one or two frames just before the end.

## Install and notes

- Install over 0.1.10 or 0.1.11-dev2; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment (which has no blur), **not on a real device**. If the closing or opening still looks wrong, send a screen recording together with the report of **Tools → Diagnostics**.

## 한국어

0.1.10 위에 얹은 테스트용 프리릴리스입니다.

### 새로운 점

- **카드가 닫힐 때 알약이 하나로 보입니다.** 카드가 접혀 들어가는 동안에는 원래 알약을 보이지 않게 해서, 위쪽의 알약과 그 안으로 들어가는 카드가 동시에 보이지 않습니다. 카드가 알약으로 돌아가는 모습 자체가 하나의 알약이고, 카드가 도착하면 알약(아이콘과 글자 포함)이 이어받은 뒤 알약 옆의 작은 원이 갈라져 나옵니다.
- **들어갈 때 회색으로 튀지 않습니다.** 카드가 유리 같은 회색에서 알약의 검정으로, 끝나기 직전 한두 프레임에 바뀌지 않고 접히는 동안 조금씩 바뀝니다.

### 설치와 참고

- 0.1.10이나 0.1.11-dev2 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경(블러가 없습니다)에서만 확인했고 **실제 기기에서는 확인하지 못했습니다.** 열리거나 닫히는 모습이 아직 이상하면 화면 녹화와 **도구 → 진단** 리포트를 함께 보내 주세요.
