# Dynamic Island 0.1.11-dev4 · Test build: blur and closing

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.10.

## What's new

- **The blur no longer drops out.** A card that opens or folds back changes its corner radius every frame, and the blur behind it was rebuilt each time, so it vanished for a frame or two and the card turned see-through (app icons showed through sharply, most visibly when several cards close one after the other). The blur is now only rebuilt when the radius changes noticeably.
- **No pill inside a pill when the cards close.** The pill takes over from the folding card only after it has grown back to the card's size, so there is no ring of card around a smaller pill.
- Includes 0.1.11-dev2 and dev3: one pill while the cards close, and the card turns from grey glass to black gradually instead of flashing grey.

## Install and notes

- Install over 0.1.10 or an earlier 0.1.11 test build; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment (which has no blur), **not on a real device**. If the opening or closing still looks wrong, send a screen recording together with the report of **Tools → Diagnostics**.

## 한국어

0.1.10 위에 얹은 테스트용 프리릴리스입니다.

### 새로운 점

- **블러가 끊기지 않습니다.** 카드가 열리거나 접힐 때는 모서리 반경이 매 프레임 바뀌는데, 그때마다 카드 뒤의 블러를 새로 만들어서 한두 프레임씩 사라졌고 카드가 투명해졌습니다(앱 아이콘이 또렷하게 비쳤고, 여러 카드가 차례로 닫힐 때 특히 눈에 띄었습니다). 이제 반경이 눈에 띄게 바뀔 때만 블러를 다시 만듭니다.
- **닫힐 때 알약 안에 알약이 보이지 않습니다.** 알약이 카드 크기만큼 다 자란 뒤에만 접히는 카드에서 알약으로 넘겨서, 작은 알약을 카드가 둘러싸는 모습이 없습니다.
- 0.1.11-dev2와 dev3의 내용이 들어 있습니다: 카드가 닫히는 동안 알약이 하나로 보이고, 카드가 회색으로 튀지 않고 회색 유리에서 검정으로 조금씩 바뀝니다.

### 설치와 참고

- 0.1.10이나 앞선 0.1.11 테스트 빌드 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경(블러가 없습니다)에서만 확인했고 **실제 기기에서는 확인하지 못했습니다.** 열리거나 닫히는 모습이 아직 이상하면 화면 녹화와 **도구 → 진단** 리포트를 함께 보내 주세요.
