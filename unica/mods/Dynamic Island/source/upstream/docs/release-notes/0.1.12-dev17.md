# Dynamic Island 0.1.12-dev17 · Keep the returning pill black

Local test APK only; no push or release.

- Keeps the compact pill's background opaque throughout folding. It no longer becomes transparent while waiting for its content to return. Existing team colours still apply to team pills.
- Keeps dev16's outer-rim-only outline fix, so a white/grey interior cannot return. The outline follows the actual body opacity.
- Content timing, opening-card glass and expanded/hidden-body fades retain their existing behaviour.
- Native Canvas pixel checks cover the returning body before content appears, partial content fades, opening/hidden states and each frame of a 60/120Hz complete fold.
