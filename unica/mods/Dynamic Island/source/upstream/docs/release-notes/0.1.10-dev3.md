# Dynamic Island 0.1.10-dev3 · Test build for Nothing OS and the switches

**English** · [한국어](#한국어)

A pre-release for testing. It adds first support for Nothing OS (AOSP-style System UI) and fixes switches that did not take effect.

## What's new

- **Nothing OS (lowest priority, not verified on a device).** On System UI builds without Samsung's ongoing-activity classes, the stock status bar chips for calls, screen recording, screen sharing and casting no longer sit next to the island. Android 16 live (promoted) notifications become island cards too, with their title, text, timer or short text, progress and buttons, and their chip and shade row are hidden. Calls and media keep their own cards. Screen recording and casting cards have no stop button yet.
- **Fixed: switches did not take effect.** Turning off *Camera & microphone in use* or *Downloads & transfers* left the card on the island until the next event; now the island follows the switch at once, and the hidden original notifications come back.
- **Fixed:** the *Downloads & transfers* switch now also covers downloads, copies and updates that an app posts as a One UI live notification.

## Install and notes

- Install over 0.1.9; it is signed with the same key. Restart System UI afterwards.
- Verified only in a headless test and render environment, **not on a real device**. If something does not work, open **Tools → Diagnostics**, copy the report (the lines `stock chips` and `hooks not attached` matter most on Nothing OS) and send it with an issue.

## 한국어

테스트용 프리릴리스입니다. Nothing OS(AOSP 계열 시스템 UI) 첫 지원과, 적용되지 않던 스위치 수정이 들어 있습니다.

### 새로운 점

- **Nothing OS 지원 (가장 낮은 우선순위, 실기기 검증 전).** 삼성 진행 중 활동 클래스가 없는 시스템 UI에서, 통화·화면 녹화·화면 공유·캐스트용 기본 상태바 칩이 더 이상 아일랜드 옆에 남지 않습니다. Android 16 라이브(프로모션) 알림도 아일랜드 카드가 되어 제목, 내용, 타이머나 짧은 글, 진행률, 버튼을 보여 주고, 그 칩과 알림창 줄은 숨겨집니다. 통화와 미디어는 원래 카드를 그대로 씁니다. 화면 녹화·캐스트 카드에는 아직 중지 버튼이 없습니다.
- **고침: 스위치가 적용되지 않던 문제.** *카메라·마이크 사용 중*이나 *다운로드 및 전송*을 꺼도 다음 이벤트까지 카드가 남아 있었는데, 이제 스위치를 바꾸는 즉시 아일랜드가 따라오고 숨겨 뒀던 원본 알림도 돌아옵니다.
- **고침:** *다운로드 및 전송* 스위치가 앱이 One UI 라이브 알림으로 올리는 다운로드·복사·업데이트도 함께 다룹니다.
